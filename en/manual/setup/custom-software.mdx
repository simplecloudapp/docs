## Add custom software

Use **Custom** for software that is not in the [supported software list](https://simplecloud.app/supported-software). When you create a [server group](/en/manual/setup/server-groups) or [persistent server](/en/manual/setup/persistent-servers), choose **Custom** in the **Software** step and fill in these fields:

| Field | What to enter |
| --- | --- |
| **Source** | Upload a `.jar` file, or enter its download URL or file path on the serverhost. |
| **Software name** | The software's name. SimpleCloud uses it to select plugins. |
| **Software version** | The software's version. |
| **Game version** | The Minecraft version. Only shown for the **Server** type. |

Then choose a **Configurator** under **Advanced**. To change these settings later, go to **Settings > Software**.

## Requirements

- **JAR file.** SimpleCloud starts the JAR with Java 21. Change the Java version, JVM options, and runtime arguments in the **Java** card under **Settings > Software**.
- **Port.** The server must listen on its assigned port, available as `%port%` in configurators and as the `SIMPLECLOUD_PORT` environment variable. SimpleCloud shows the server as available once it answers a status ping on that port.
- **Configurator.** The [configurator](/en/manual/configuration/configurators) writes the port and proxy settings. Choose a preset that fits your software, or create your own.
- **Plugins.** SimpleCloud plugins are installed only when the software name is a supported plugin platform, such as `paper` or `velocity`.

## Bedrock servers

Bedrock servers that start from a JAR run through **Custom**:

- Register the server on your Bedrock proxy yourself. SimpleCloud's proxy plugins do not do this.
- Add it to Server Connection's `registration.ignore-server-groups-and-persistent-servers` so Velocity and BungeeCord do not send Java players there.
- Use a [custom configurator](/en/manual/configuration/configurators) that writes `%port%` to your server's configuration.
- To use the [Cloud API](/en/developer/installation), shade it into your own plugin.
