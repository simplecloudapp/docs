## Overview

The SimpleCloud Dashboard is the main place to create networks, run onboarding, manage server groups and persistent servers, inspect logs, and invite team members.

<Frame>
  <img src="https://github.com/simplecloudapp/branding/blob/main/media/dashboard/serveroverview.png?raw=true" alt="SimpleCloud Dashboard" />
</Frame>

## Open the dashboard

Open the dashboard in your browser:

[dash.simplecloud.app](https://dash.simplecloud.app)

Sign in with your SimpleCloud account. If the network has no connected serverhost yet, the dashboard opens the onboarding wizard and generates the setup command for you.

## Create a server group

Use groups for scalable sets of interchangeable servers, such as proxies, lobbies, or minigames.

<Steps>
  <Step title="Open Groups">
    Open **Groups** in the dashboard and click **Add Group**.
  </Step>

  <Step title="Set the group identity">
    Choose the name, type, and whether the group should activate immediately.
  </Step>

  <Step title="Choose software and resources">
    Select the server software, memory, player limit, scaling mode, and host deployment settings.
  </Step>

  <Step title="Add plugins">
    Add plugins from the supported plugin sources, or skip this step and add them later in group settings.
  </Step>

  <Step title="Create the group">
    Review the summary and click **Create Group**.
  </Step>
</Steps>

For the full workflow, see [Server Groups](/en/manual/setup/server-groups).
