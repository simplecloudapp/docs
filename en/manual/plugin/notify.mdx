## Supported software

| Software   | Supported |
| ---------- | --------- |
| Velocity   | Yes       |
| BungeeCord | Yes       |

## Install the plugin

<Steps>
  <Step title="Install the plugin">
    Download Notify from [GitHub](https://github.com/simplecloudapp/simplecloud-plugins/releases) or [Modrinth](https://modrinth.com/organization/simplecloud) and place the JAR in the proxy template's `plugins/` folder.
  </Step>

  <Step title="Give permissions">
    Give your team the permissions for the notifications they should receive, for example `notify.state.server.available`. See [Permissions](#permissions).
  </Step>

  <Step title="Verify the notifications">
    Start a proxy, join it, and start a new server.

    <Check>
      You receive a message when the server is starting and when it is available.
    </Check>
  </Step>
</Steps>

You can change all messages in `plugins/simplecloud-notify/messages.yml`.

## Notifications

| Type | Sent when |
| ---- | --------- |
| `server.starting` | A server is starting |
| `server.available` | A server is available |
| `server.stopping` | A server is stopping |
| `server.stopped` | A server has stopped |
| `group.created` | A group was created |
| `group.deleted` | A group was deleted |
| `persistent-server.created` | A persistent server was created |
| `persistent-server.deleted` | A persistent server was deleted |

A player receives a notification if they have its permission and have not turned it off.

## Turn notifications on or off

Every player can turn all notifications or single types on and off:

```text
/scnotify disable
/scnotify enable server.starting
```

`/scnotify list` shows all types you can receive and whether they are on. Click an entry to toggle it.

Notify saves this choice in the player's SimpleCloud properties, so it works on every proxy. All notifications are on by default.

## Commands

| Command | Description |
| ------- | ----------- |
| `/scnotify` or `/scnotify help` | Show the commands you can use |
| `/scnotify list` | Show your notification types and whether they are on |
| `/scnotify enable [type]` | Turn all notifications or one type on |
| `/scnotify disable [type]` | Turn all notifications or one type off |
| `/scnotify set <player> <true\|false> [type]` | Turn notifications on or off for an online player |
| `/scnotify reload config` | Reload the plugin |

## Permissions

| Permission | Description |
| ---------- | ----------- |
| `notify.state.server.starting` | Receive server starting notifications |
| `notify.state.server.available` | Receive server available notifications |
| `notify.state.server.stopping` | Receive server stopping notifications |
| `notify.state.server.stopped` | Receive server stopped notifications |
| `notify.state.group.created` | Receive group created notifications |
| `notify.state.group.deleted` | Receive group deleted notifications |
| `notify.state.persistent-server.created` | Receive persistent server created notifications |
| `notify.state.persistent-server.deleted` | Receive persistent server deleted notifications |
| `simplecloud.command.notify.help` | Use `/scnotify` and `/scnotify help` |
| `simplecloud.command.notify.reload.config` | Use `/scnotify reload config` |
| `simplecloud.command.notify.toggle.self` | Use `list`, `enable`, and `disable` |
| `simplecloud.command.notify.toggle.other` | Use `/scnotify set` |

## Troubleshooting

<AccordionGroup>
  <Accordion title="The proxy does not load Notify">
    Make sure `simplecloud-api` is installed on the same proxy. Notify does not start without it.
  </Accordion>

  <Accordion title="A player receives no notifications">
    Check that the player has the permission for the type. Then run `/scnotify list` as that player to see if the type is turned off.
  </Accordion>
</AccordionGroup>
