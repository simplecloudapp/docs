## Install the plugin

<Steps>
  <Step title="Install the plugin">
    Download Cloud Command from [GitHub](https://github.com/simplecloudapp/simplecloud-plugins/releases) or [Modrinth](https://modrinth.com/organization/simplecloud) and place the JAR in the proxy template's `plugins/` folder.
  </Step>

  <Step title="Verify the commands">
    Start a proxy, give yourself `simplecloud.command.use`, and run `/cloud`.

    <Check>
      The help menu lists the commands you have permission to use.
    </Check>
  </Step>
</Steps>

You can change all messages in `plugins/simplecloud-command/messages.yml`.

## Commands

You can use `/cloud`, `/sc`, or `/simplecloud`.

### Groups

| Command | Description |
| ------- | ----------- |
| `/cloud group list` | List all groups with their online servers |
| `/cloud group info <group>` | Show type, memory, max players, and running servers of a group |
| `/cloud group start <group> [count]` | Start one or more servers, up to 50 at once |
| `/cloud group stop <group> [id]` | Stop all servers of a group, or only the server with this numerical ID |

### Servers

| Command | Description |
| ------- | ----------- |
| `/cloud server list [group]` | List running servers, optionally only of one group |
| `/cloud server info <group> <id>` | Show state, memory, and players of a server |
| `/cloud server start <group>` | Start one new server |
| `/cloud server stop <group> <id>` | Stop one server |

### Players

For targets, use `group` for a group or `ps` for a persistent server.

| Command | Description |
| ------- | ----------- |
| `/cloud player list <group\|ps> <target>` | List the players on a target |
| `/cloud player info <player>` | Show server, proxy, online time, first seen, and last seen of a player |
| `/cloud player send <player> <group\|ps> <target>` | Send a player to a target |
| `/cloud player sendall <group\|ps> <target>` | Send all online players to a target |
| `/cloud player sendfrom <source> <group\|ps> <target>` | Send all players on a source to a target |
| `/cloud player message <player> <message>` | Send a plain text message to a player |

The `<source>` of `sendfrom` can be a group, a server such as `Lobby-1`, or a persistent server.

### Other

| Command | Description |
| ------- | ----------- |
| `/cloud reload` | Reload the plugin |

## Permissions

| Permission | Description |
| ---------- | ----------- |
| `simplecloud.command.use` | Use `/cloud` and see the help menu |
| `simplecloud.command.group.list` | Use `/cloud group list` |
| `simplecloud.command.group.info` | Use `/cloud group info` |
| `simplecloud.command.group.start` | Use `/cloud group start` |
| `simplecloud.command.group.stop` | Use `/cloud group stop` |
| `simplecloud.command.server.list` | Use `/cloud server list` |
| `simplecloud.command.server.info` | Use `/cloud server info` |
| `simplecloud.command.server.start` | Use `/cloud server start` |
| `simplecloud.command.server.stop` | Use `/cloud server stop` |
| `simplecloud.command.player.list` | Use `/cloud player list` |
| `simplecloud.command.player.info` | Use `/cloud player info` |
| `simplecloud.command.player.send` | Use `send`, `sendall`, and `sendfrom` |
| `simplecloud.command.player.message` | Use `/cloud player message` |
| `simplecloud.command.reload` | Use `/cloud reload` |

The help menu only shows the commands you have permission for.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The proxy does not load Cloud Command">
    Make sure `simplecloud-api` is installed on the same proxy. Cloud Command does not start without it.
  </Accordion>

  <Accordion title="A command is missing from the help menu">
    Give yourself the matching permission. The help menu hides commands you cannot use.
  </Accordion>

</AccordionGroup>
