## Overview

The Prefixes plugin shows player rank information in chat and tab lists. It reads LuckPerms groups, converts group prefix, suffix, color, and weight data into Prefixes groups, and formats text with Adventure Components and MiniMessage.

Use this plugin when a server should display the same rank identity in chat and in the tab list.

## Supported Software

| Runtime | Package | Requirements | Status |
| ------- | ------- | ------------ | ------ |
| Paper and forks | Paper plugin | LuckPerms and CustomNames | Supported |
| Minestom | Minestom extension | LuckPerms Minestom API | Experimental |

<Warning>
  The Paper plugin requires both LuckPerms and CustomNames. The Minestom extension exists in the source tree, but its LuckPerms integration is marked experimental.
</Warning>

## Quick Setup

<Steps>
  <Step title="Install dependencies">
    Install LuckPerms and CustomNames on the server template that should display prefixes.
  </Step>

  <Step title="Install Prefixes">
    Download the plugin from [GitHub](https://github.com/simplecloudapp/prefixes-plugin/releases) and place it in the server template's `plugins/` folder.
  </Step>

  <Step title="Generate the config">
    Start the server once so the plugin creates `config.json`.
  </Step>

  <Step title="Configure LuckPerms groups">
    Set each group's prefix, suffix, color, and weight in LuckPerms. Prefixes uses the LuckPerms group weight as the tab list priority.

    ```bash
    /lp group admin meta addprefix 100 "<red>[Admin] "
    /lp group admin meta addsuffix 100 " <gray>*"
    /lp group admin meta set color "#FF0000"
    /lp group admin setweight 100
    ```
  </Step>

  <Step title="Adjust chat formatting">
    Edit `config.json` if you want to change how chat messages are rendered.

    <Check>
      When a player joins, their chat name and tab list name should use the prefix, suffix, color, and weight from their primary LuckPerms group.
    </Check>
  </Step>
</Steps>

## Configuration

`config.json` controls the chat format. The default format is:

```json config.json
{
  "chatFormat": "<prefix><name_colored><suffix><gray>:</gray> <white><message></white>"
}
```

## Chat Placeholders

| Placeholder | Description |
| ----------- | ----------- |
| `<prefix>` | Prefix from the player's resolved Prefixes group |
| `<suffix>` | Suffix from the player's resolved Prefixes group |
| `<name>` | Player name without team color |
| `<name_colored>` | Player name with the resolved team color |
| `<message>` | Chat message content |

## LuckPerms Mapping

| LuckPerms value | Prefixes value |
| --------------- | -------------- |
| Group name | Prefixes group name |
| Group prefix | Display prefix |
| Group suffix | Display suffix |
| `color` meta value | Team color |
| Group weight | Tab list priority |
| User primary group | Player's active Prefixes group |

## API Usage

import app.simplecloud.plugin.prefixes.api.PrefixesApi

val registration = Bukkit.getServicesManager()
    .getRegistration(PrefixesApi::class.java)

    ?: error("PrefixesApi is not registered")

### Update a Player

```kotlin
import net.kyori.adventure.text.Component
import net.kyori.adventure.text.format.NamedTextColor

prefixesApi.setPrefix(player.uniqueId, Component.text("[VIP] "))
prefixesApi.setSuffix(player.uniqueId, Component.text(" *"))
prefixesApi.setColor(player.uniqueId, NamedTextColor.GOLD)
```

### Register a Custom Group

```kotlin
import app.simplecloud.plugin.prefixes.api.PrefixesGroup
import net.kyori.adventure.text.Component
import net.kyori.adventure.text.format.NamedTextColor
import net.kyori.adventure.text.format.TextColor
import java.util.UUID
import java.util.concurrent.CompletableFuture

class VipGroup : PrefixesGroup {
    override fun getName(): String = "vip"
    override fun getPrefix(): Component = Component.text("[VIP] ")
    override fun getSuffix(): Component = Component.text(" *")
    override fun getColor(): TextColor = NamedTextColor.GOLD
    override fun getPriority(): Int = 50

    override fun containsPlayer(uniqueId: UUID): Boolean {
        return containsPlayerFuture(uniqueId).join()
    }

    override fun containsPlayerFuture(uniqueId: UUID): CompletableFuture<Boolean> {
        return CompletableFuture.completedFuture(false)
    }
}

prefixesApi.addGroup(VipGroup())
```

## Best Practices

- Keep LuckPerms group weights unique so tab list ordering is predictable.
- Store prefixes and suffixes as MiniMessage strings in LuckPerms.
- Use the `color` meta value for team color instead of embedding the player name color in every prefix.
- Keep `chatFormat` simple enough that chat remains readable on small screens.
