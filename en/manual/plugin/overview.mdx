## Install plugins

### Use the dashboard

When you create or edit a group, add plugins in its **Plugins** settings. New servers in that group start with the selected plugins. For a group that is already running, save the change and use **Hold to rolling restart** to replace its instances one at a time.

### Use the CLI

```bash
# List plugins for a group
sc group plugin list lobby

# Add a plugin to a proxy group
sc group plugin add proxy proxy-essentials

# Add a plugin to a persistent proxy
sc persistent-server plugin add proxy-main proxy-essentials

# Remove a plugin from a group
sc group plugin remove proxy proxy-essentials
```

The optional plugin query can be a search term, a Modrinth slug such as `mr:luckperms`, a Spigot ID such as `sp:28140`, or a plugin URL.

### Install a JAR manually

Place a plugin JAR in the `plugins/` folder of the matching template:

```bash
cp my-plugin.jar templates/lobby/plugins/
```

## Plugins and droplets

| | Plugins | Droplets |
|---|---------|----------|
| **Runs on** | Inside a Minecraft server or proxy | As an independent service |
| **Purpose** | In-game features | Infrastructure tasks |
| **Examples** | Signs, NPCs, commands | Player data, resource packs |

Use the [Cloud API developer docs](/en/developer/overview) to build Minecraft plugins. Droplet development documentation is not available yet.
