The Events API lets you react to changes in your network in real-time. Access it via `api.event()`.

## Event Categories

| Method | Events |
|--------|--------|
| `api.event().group()` | Group created, updated, deleted |
| `api.event().server()` | Server started, stopped, state changed, updated, deleted |
| `api.event().persistentServer()` | Persistent server created, started, stopped, updated, deleted |
| `api.event().blueprint()` | Blueprint created, updated, deleted |

## Server Events

### Server Started

Fires when a server instance becomes active. The event includes the full `Server` object with all runtime information.

<CodeGroup>
```java Java
Subscription sub = api.event().server().onStarted(event -> {
    System.out.println("Server started: " + event.getServerId());
    System.out.println("Network: " + event.getNetworkId());

    Server server = event.getServer();
    if (server.isFromGroup()) {
        System.out.println("Group: " + server.getServerGroupId());
    } else if (server.isFromPersistentServer()) {
        System.out.println("Persistent server: " + server.getPersistentServerId());
    }
});
```

```kotlin Kotlin
val sub = api.event().server().onStarted { event ->
    println("Server started: ${event.serverId}")
    println("Network: ${event.networkId}")

    val server = event.server
    if (server.isFromGroup()) {
        println("Group: ${server.serverGroupId}")
    } else if (server.isFromPersistentServer()) {
        println("Persistent server: ${server.persistentServerId}")
    }
}
```
</CodeGroup>

### Server Stopped

Fires when a server instance stops. Use `getCrashed()` to detect unexpected shutdowns.

<CodeGroup>
```java Java
api.event().server().onStopped(event -> {
    System.out.println("Server stopped: " + event.getServerId());

    if (event.getCrashed()) {
        System.out.println("Server crashed! Exit code: " + event.getExitCode());
        System.out.println("Reason: " + event.getReason());
    }
});
```

```kotlin Kotlin
api.event().server().onStopped { event ->
    println("Server stopped: ${event.serverId}")

    if (event.crashed) {
        println("Server crashed! Exit code: ${event.exitCode}")
        println("Reason: ${event.reason}")
    }
}
```
</CodeGroup>

### Server State Changed

Fires whenever a server transitions between lifecycle states.

<CodeGroup>
```java Java
api.event().server().onStateChanged(event -> {
    System.out.println(event.getServerId() + ": " +
        event.getOldState() + " → " + event.getNewState());

    if (event.getNewState() == ServerState.AVAILABLE) {
        System.out.println("Server ready: " + event.getServerId());
    }
});
```

```kotlin Kotlin
api.event().server().onStateChanged { event ->
    println("${event.serverId}: ${event.oldState} → ${event.newState}")

    if (event.newState == ServerState.AVAILABLE) {
        println("Server ready: ${event.serverId}")
    }
}
```
</CodeGroup>

### Server Updated

<CodeGroup>
```java Java

    System.out.println("Player count: " + server.getPlayerCount());
});
```

```kotlin Kotlin
api.event().server().onUpdated { event ->

```
</CodeGroup>

## Managing Subscriptions

Subscriptions implement `AutoCloseable`. Always clean them up when done.

### Manual Cleanup

<CodeGroup>
```java Java
Subscription sub = api.event().server().onStarted(event -> { ... });

// When shutting down
sub.close();
```

```kotlin Kotlin
val sub = api.event().server().onStarted { event -> /* ... */ }

// When shutting down
sub.close()
```
</CodeGroup>

### Try-with-Resources

<CodeGroup>
```java Java
try (Subscription sub = api.event().server().onStarted(event -> { ... })) {
    // Subscription active within this block
    Thread.sleep(60000);
} // Automatically closed
```

```kotlin Kotlin
api.event().server().onStarted { event -> /* ... */ }.use {
    // Subscription active within this block
    Thread.sleep(60000)
} // Automatically closed
```
</CodeGroup>

### Plugin Lifecycle

<CodeGroup>
```java Java
public class MyPlugin extends JavaPlugin {
    private final List<Subscription> subscriptions = new ArrayList<>();
    private CloudApi api;

    @Override
    public void onEnable() {
        api = CloudApi.create();

        subscriptions.add(api.event().server().onStarted(this::handleServerStart));
        subscriptions.add(api.event().server().onStopped(this::handleServerStop));
        subscriptions.add(api.event().group().onUpdated(this::handleGroupUpdate));
    }

    @Override
    public void onDisable() {
        subscriptions.forEach(Subscription::close);
        subscriptions.clear();
    }

    private void handleServerStart(ServerStartedEvent event) {
        getLogger().info("Server started: " + event.getServerId());
    }

    private void handleServerStop(ServerStoppedEvent event) {
        getLogger().info("Server stopped: " + event.getServerId());
    }

    private void handleGroupUpdate(GroupUpdatedEvent event) {
        getLogger().info("Group updated: " + event.getServerGroupId());
    }
}
```

```kotlin Kotlin
class MyPlugin : JavaPlugin() {
    private val subscriptions = mutableListOf<Subscription>()
    private lateinit var api: CloudApi

    override fun onEnable() {
        api = CloudApi.create()

        subscriptions.add(api.event().server().onStarted(::handleServerStart))
        subscriptions.add(api.event().server().onStopped(::handleServerStop))
        subscriptions.add(api.event().group().onUpdated(::handleGroupUpdate))
    }

    override fun onDisable() {
        subscriptions.forEach { it.close() }
        subscriptions.clear()
    }

    private fun handleServerStart(event: ServerStartedEvent) {
        logger.info("Server started: ${event.serverId}")
    }

    private fun handleServerStop(event: ServerStoppedEvent) {
        logger.info("Server stopped: ${event.serverId}")
    }

    private fun handleGroupUpdate(event: GroupUpdatedEvent) {
        logger.info("Group updated: ${event.serverGroupId}")
    }
}
```
</CodeGroup>

## Event Reference

### Server Events

| Event | Key Properties |
|-------|----------------|
| `ServerStartedEvent` | `serverId`, `serverGroupId`, `server`, `networkId`, `timestamp` |
| `ServerStoppedEvent` | `serverId`, `serverGroupId`, `server`, `crashed`, `exitCode`, `reason`, `networkId`, `timestamp` |
| `ServerStateChangedEvent` | `serverId`, `oldState`, `newState`, `server`, `networkId`, `timestamp` |
| `ServerUpdatedEvent` | `serverId`, `serverGroupId`, `server`, `networkId`, `timestamp` |
| `ServerDeletedEvent` | `serverId`, `serverGroupId`, `server`, `networkId`, `timestamp` |

<Note>
  `ServerStartedEvent` and `ServerStoppedEvent` fire for both group servers and persistent servers. Use `server.isFromGroup()` or `server.isFromPersistentServer()` to distinguish them.
</Note>

### Group Events

| Event | Key Properties |
|-------|----------------|
| `GroupCreatedEvent` | `serverGroupId`, `group`, `networkId`, `timestamp` |
| `GroupUpdatedEvent` | `serverGroupId`, `group`, `networkId`, `timestamp` |
| `GroupDeletedEvent` | `serverGroupId`, `name`, `networkId`, `timestamp` |

### Persistent Server Events

| Event | Key Properties |
|-------|----------------|
| `PersistentServerCreatedEvent` | `persistentServerId`, `name`, `networkId`, `timestamp` |
| `PersistentServerStartedEvent` | `persistentServerId`, `serverId`, `networkId`, `timestamp` |
| `PersistentServerStoppedEvent` | `persistentServerId`, `serverId`, `networkId`, `timestamp` |
| `PersistentServerUpdatedEvent` | `persistentServerId`, `name`, `networkId`, `timestamp` |
| `PersistentServerDeletedEvent` | `persistentServerId`, `name`, `networkId`, `timestamp` |

### Blueprint Events

| Event | Key Properties |
|-------|----------------|

| `BlueprintUpdatedEvent` | `blueprintId`, `blueprint`, `networkId`, `timestamp` |
