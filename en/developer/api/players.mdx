The Players API lets you query players, transfer them between servers, and send rich-text messages using Adventure. Access it via `api.player()`.

## Get Players

<CodeGroup>
```java Java
// Get player by UUID
api.player().get(uuid)
    .thenAccept(player -> {
        if (player != null) {
            System.out.println(player.getName() + " on " + player.getConnectedServerName());
        }
    });

// Get player by username (case-insensitive)
api.player().get("Steve")
    .thenAccept(player -> { ... });

// Get all online players
api.player().getOnlinePlayers()
    .thenAccept(players -> players.forEach(p ->
        System.out.println(p.getName())));

// Get online player count
api.player().getOnlinePlayerCount()
    .thenAccept(count -> System.out.println("Online: " + count));
```

```kotlin Kotlin
// in a coroutine scope (e.g. plugin lifecycle or launch { })

// Get player by UUID
val player = api.player().get(uuid).await()
if (player != null) {
    println("${player.name} on ${player.connectedServerName}")
}

// Get player by username (case-insensitive)
val steve = api.player().get("Steve").await()

// Get all online players
val players = api.player().getOnlinePlayers().await()
players.forEach { p -> println(p.name) }

// Get online player count
val count = api.player().getOnlinePlayerCount().await()
println("Online: $count")
```
</CodeGroup>

## Player Actions

### Transfer Player

<CodeGroup>
```java Java
api.player().get(uuid).thenAccept(player -> {
    if (player != null) {
        player.connect("lobby-1").thenAccept(result -> {
            switch (result) {
                case SUCCESS -> System.out.println("Transferred!");
                case SERVER_NOT_FOUND -> System.out.println("Server doesn't exist");
                case ALREADY_CONNECTED -> System.out.println("Already on that server");
                case PLAYER_NOT_FOUND -> System.out.println("Player went offline");
                case CONNECTION_FAILED -> System.out.println("Connection failed");
            }
        });
    }
});
```

```kotlin Kotlin
val player = api.player().get(uuid).await() ?: return
val result = player.connect("lobby-1").await()
when (result) {
    CloudPlayer.ConnectResult.SUCCESS -> println("Transferred!")
    CloudPlayer.ConnectResult.SERVER_NOT_FOUND -> println("Server doesn't exist")
    CloudPlayer.ConnectResult.ALREADY_CONNECTED -> println("Already on that server")
    CloudPlayer.ConnectResult.PLAYER_NOT_FOUND -> println("Player went offline")
    CloudPlayer.ConnectResult.CONNECTION_FAILED -> println("Connection failed")
}
```
</CodeGroup>

## Player Properties

Players support custom properties stored on the controller:

<CodeGroup>
```java Java
// Update properties (merge with existing)
api.player().updatePlayerProperties(uuid, Map.of(
    "rank", "VIP",
    "coins", "1500"
)).thenAccept(props -> System.out.println("Updated: " + props));

// Update a single property
api.player().updatePlayerProperty(uuid, "rank", "MVP")
    .thenAccept(props -> System.out.println("Updated: " + props));

// Remove specific properties
api.player().deletePlayerProperties(uuid, List.of("coins"))
    .thenAccept(remaining -> System.out.println("Remaining: " + remaining));

// Remove a single property
api.player().deletePlayerProperty(uuid, "rank")
    .thenAccept(remaining -> System.out.println("Remaining: " + remaining));
```

```kotlin Kotlin
// Update properties (merge with existing)
val props = api.player().updatePlayerProperties(uuid, mapOf(
    "rank" to "VIP",
    "coins" to "1500"
)).await()
println("Updated: $props")

// Update a single property
val updatedProps = api.player().updatePlayerProperty(uuid, "rank", "MVP").await()
println("Updated: $updatedProps")

// Remove specific properties
val remaining = api.player().deletePlayerProperties(uuid, listOf("coins")).await()
println("Remaining: $remaining")

// Remove a single property
val remainingAfter = api.player().deletePlayerProperty(uuid, "rank").await()
println("Remaining: $remainingAfter")
```
</CodeGroup>

<Note>
  Player properties use `Map<String, String>` (string values only), unlike group and server properties which use `Map<String, Object>`.
</Note>

## Adventure Integration

`CloudPlayer` implements Adventure's `Audience` interface, giving you access to all Adventure messaging features:

### Send Messages

<CodeGroup>
```java Java
// Plain text
player.sendMessage(Component.text("Hello!"));

// Colored text
player.sendMessage(Component.text("Success!")
    .color(NamedTextColor.GREEN));

// Styled text
player.sendMessage(Component.text("Important")
    .color(NamedTextColor.GOLD)
    .decorate(TextDecoration.BOLD));

// Clickable text
player.sendMessage(Component.text("Click here")
    .clickEvent(ClickEvent.runCommand("/help"))
    .hoverEvent(HoverEvent.showText(Component.text("Run /help"))));
```


## Broadcast to All Players

<CodeGroup>
```java Java
api.player().getOnlinePlayers().thenAccept(players -> {
    Component message = Component.text("[Announcement] ")
        .color(NamedTextColor.GOLD)
        .append(Component.text("Server restarting in 5 minutes")
            .color(NamedTextColor.WHITE));

    players.forEach(player -> player.sendMessage(message));
});
```

```kotlin Kotlin
val players = api.player().getOnlinePlayers().await()
val message = Component.text("[Announcement] ")
    .color(NamedTextColor.GOLD)
    .append(Component.text("Server restarting in 5 minutes")
        .color(NamedTextColor.WHITE))

players.forEach { player -> player.sendMessage(message) }
```
</CodeGroup>

## CloudPlayer Model

<ResponseField name="uniqueId" type="UUID">
  Player's unique identifier.
</ResponseField>

<ResponseField name="name" type="String">
  Player's username.
</ResponseField>

<ResponseField name="displayName" type="String">
  Player's display name.
</ResponseField>

<ResponseField name="connectedServerName" type="String">
  Name of the server the player is currently on.
</ResponseField>

<ResponseField name="connectedProxyName" type="String">
  Name of the proxy the player is connected through.
</ResponseField>

<ResponseField name="online" type="boolean">
  Whether the player is currently online.
</ResponseField>

<ResponseField name="onlineTimeSeconds" type="long">
  Accumulated online time in seconds.
</ResponseField>

<ResponseField name="sessionId" type="String">
  Active session identifier.
</ResponseField>

<ResponseField name="firstSeen" type="String">
  ISO 8601 timestamp of the player's first login.
</ResponseField>

<ResponseField name="lastSeen" type="String">
  ISO 8601 timestamp of the player's most recent login.
</ResponseField>

<ResponseField name="properties" type="Map<String, String>">
  Custom player properties (immutable map; empty if none).
</ResponseField>

## ConnectResult

| Value | Description |
|-------|-------------|
| `SUCCESS` | Transfer successful |
| `SERVER_NOT_FOUND` | Target server does not exist |
| `ALREADY_CONNECTED` | Player is already on that server |
| `PLAYER_NOT_FOUND` | Player went offline before the transfer completed |
| `CONNECTION_FAILED` | Transfer failed for an unknown reason |
