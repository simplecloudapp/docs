title: 'Servers API'
description: 'Query and manage running server instances'

The Servers API lets you query, stop, and update running server instances. Access it via `api.server()`.

## Get Servers

<CodeGroup>
```java Java
// Get all servers
api.server().getAllServers()
    .thenAccept(servers -> System.out.println("Total: " + servers.size()));

// Get servers with query filters
ServerQuery query = ServerQuery.create()
    .filterByServerGroupName("lobby")
    .filterByState(ServerState.AVAILABLE, ServerState.INGAME)
    .sortBy("numerical_id")
    .sortOrder("asc");
api.server().getAllServers(query)
    .thenAccept(servers -> servers.forEach(s ->
        System.out.println(s.getServerId() + ": " + s.getState())));

// Get server by unique ID
api.server().getServerById("server-uuid")
    .thenAccept(server -> System.out.println(server.getState()));

// Get all servers in a group
api.server().getServersByGroup("lobby")
    .thenAccept(servers -> servers.forEach(s ->
        System.out.println(s.getServerId() + ": " + s.getState())));

// Get server by group name and numerical ID (e.g., Lobby-1)
api.server().getServerByNumericalId("lobby", 1)
    .thenAccept(server -> System.out.println(server.getServerId()));

// Get the current server (from within a running server)
api.server().getCurrentServer()
    .thenAccept(server -> System.out.println("Running on: " + server.getServerId()));
```

```kotlin Kotlin

// Get all servers
val servers = api.server().getAllServers().await()
println("Total: ${servers.size}")

// Get servers with query filters
val query = ServerQuery.create()
    .filterByServerGroupName("lobby")
    .filterByState(ServerState.AVAILABLE, ServerState.INGAME)
    .sortBy("numerical_id")
    .sortOrder("asc")
val filteredServers = api.server().getAllServers(query).await()
filteredServers.forEach { s -> println("${s.serverId}: ${s.state}") }

// Get server by unique ID
val server = api.server().getServerById("server-uuid").await()
println(server.state)

// Get all servers in a group
val groupServers = api.server().getServersByGroup("lobby").await()
groupServers.forEach { s -> println("${s.serverId}: ${s.state}") }

// Get server by group name and numerical ID (e.g., Lobby-1)
val lobbyOne = api.server().getServerByNumericalId("lobby", 1).await()
println(lobbyOne.serverId)

// Get the current server (from within a running server)
val currentServer = api.server().getCurrentServer().await()
println("Running on: ${currentServer.serverId}")
```
</CodeGroup>

## Stop Server

<CodeGroup>
```java Java
api.server().stopServer("server-uuid")
    .thenRun(() -> System.out.println("Stop initiated"));
```

```kotlin Kotlin
api.server().stopServer("server-uuid").await()
println("Stop initiated")
```
</CodeGroup>

## Update Server

`UpdateServerRequest` uses setter methods. Only the fields you set are changed:

<CodeGroup>
```java Java
UpdateServerRequest update = new UpdateServerRequest();
update.setMaxPlayers(64);
update.setState(ServerState.AVAILABLE);

api.server().updateServer("server-uuid", update)
    .thenAccept(server -> System.out.println("Updated: " + server.getMaxPlayers()));
```

```kotlin Kotlin
val update = UpdateServerRequest().apply {
    maxPlayers = 64
    state = ServerState.AVAILABLE
}

val updatedServer = api.server().updateServer("server-uuid", update).await()
println("Updated: ${updatedServer.maxPlayers}")
```
</CodeGroup>

## Server Properties

Servers support custom properties for runtime metadata:

<CodeGroup>
```java Java
// Add or update properties (deep merge with existing)
api.server().updateServerProperties("server-uuid", Map.of(
    "map", "castle",
    "mode", "competitive"
)).thenAccept(props -> System.out.println("Updated: " + props));

// Update a single property
api.server().updateServerProperty("server-uuid", "map", "desert")
    .thenAccept(props -> System.out.println("Updated: " + props));

// Remove specific properties
api.server().deleteServerProperties("server-uuid", List.of("mode"))
    .thenAccept(remaining -> System.out.println("Remaining: " + remaining));

// Remove a single property
api.server().deleteServerProperty("server-uuid", "mode")
    .thenAccept(remaining -> System.out.println("Remaining: " + remaining));
```

```kotlin Kotlin
// Add or update properties (deep merge with existing)
val props = api.server().updateServerProperties("server-uuid", mapOf(
    "map" to "castle",
    "mode" to "competitive"
)).await()
println("Updated: $props")

// Update a single property
val updatedProps = api.server().updateServerProperty("server-uuid", "map", "desert").await()
println("Updated: $updatedProps")

// Remove specific properties
val remaining = api.server().deleteServerProperties("server-uuid", listOf("mode")).await()
println("Remaining: $remaining")

// Remove a single property
val remainingAfter = api.server().deleteServerProperty("server-uuid", "mode").await()
println("Remaining: $remainingAfter")
```
</CodeGroup>

## ServerQuery

Use `ServerQuery.create()` to build filtered queries:

| Method | Description |
|--------|-------------|
| `filterByServerGroupId(String...)` | Filter by one or more group IDs |
| `filterByServerGroupName(String...)` | Filter by one or more group names |
| `filterByServerGroupTags(String...)` | Filter by group tags (matches if any tag matches) |
| `filterByServerGroupType(GroupServerType...)` | Filter by group type (`SERVER`, `PROXY`) |
| `filterByState(ServerState...)` | Filter by one or more server states |
| `filterByServerhostId(String)` | Filter by the host machine ID |
| `filterByPersistentServerId(String)` | Filter servers spawned from a specific persistent server |
| `filterByNumericalId(Integer...)` | Filter by numerical IDs (e.g., 1, 5, 10) |
| `sortBy(String)` | Sort field: `created_at`, `updated_at`, `numerical_id`, `state` |
| `sortOrder(String)` | `"asc"` or `"desc"` |

## Server Model

<ResponseField name="serverId" type="String">
  Unique identifier for this server instance.
</ResponseField>

<ResponseField name="numericalId" type="int">
  Sequential number within the group (e.g., 1 for Lobby-1).
</ResponseField>

<ResponseField name="serverGroupId" type="String?">
  ID of the parent group. Null if this server was spawned from a persistent server.
</ResponseField>

<ResponseField name="persistentServerId" type="String?">
  ID of the parent persistent server. Null if this server was spawned from a group.
</ResponseField>

<ResponseField name="serverhostId" type="String">
  ID of the host machine running this server.
</ResponseField>

<ResponseField name="networkId" type="String">
  Network this server belongs to.
</ResponseField>

<ResponseField name="ip" type="String?">
  IP address where this server is accessible. Null until assigned.
</ResponseField>

<ResponseField name="port" type="Integer?">
  Port this server listens on. Null until assigned.
</ResponseField>

<ResponseField name="minMemory" type="Integer">
  Minimum memory allocation in MB.
</ResponseField>

<ResponseField name="maxMemory" type="Integer">
  Maximum memory allocation in MB.
</ResponseField>

<ResponseField name="maxPlayers" type="Integer">
  Maximum player limit.
</ResponseField>

<ResponseField name="playerCount" type="Integer?">
  Current number of connected players.
</ResponseField>

<ResponseField name="cpuUsage" type="Double?">
  Current CPU usage as a percentage (0.0–100.0).
</ResponseField>

<ResponseField name="memoryUsage" type="Double?">
  Current memory usage in MB.
</ResponseField>

<ResponseField name="state" type="ServerState">
  Current lifecycle state.
</ResponseField>

<ResponseField name="properties" type="Map<String, Object>?">
  Custom metadata key-value pairs.
</ResponseField>

<ResponseField name="blueprint" type="Blueprint?">
  Blueprint this server was created from, if any.
</ResponseField>

<ResponseField name="createdAt" type="String">
  ISO 8601 creation timestamp.
</ResponseField>

<ResponseField name="updatedAt" type="String">
  ISO 8601 last-updated timestamp.
</ResponseField>

<ResponseField name="lastActivity" type="String?">
  ISO 8601 timestamp of the last activity on this server.
</ResponseField>

### Accessing the Parent Configuration

A server can be spawned from either a group or a persistent server. Use the following methods to access the parent:

<CodeGroup>
```java Java
// Access parent regardless of type (ServerBase covers both Group and PersistentServer)
ServerBase base = server.getServerBase();
System.out.println(base.getName());

// Check the type
if (server.isFromGroup()) {
    Group group = server.getGroup();
    System.out.println("Group: " + group.getServerGroupId());
} else if (server.isFromPersistentServer()) {
    PersistentServer ps = server.getPersistentServer();
    System.out.println("Persistent server: " + ps.getPersistentServerId());
}
```

```kotlin Kotlin
// Access parent regardless of type (ServerBase covers both Group and PersistentServer)
val base = server.serverBase
println(base.name)

// Check the type
if (server.isFromGroup()) {
    val group = server.group
    println("Group: ${group.serverGroupId}")
} else if (server.isFromPersistentServer()) {
    val ps = server.persistentServer
    println("Persistent server: ${ps.persistentServerId}")
}
```
</CodeGroup>

## ServerState

| State | Description |
|-------|-------------|
| `UNKNOWN_STATE` | Unknown or unspecified state |
| `PREPARING` | Downloading files, setting up server environment |
| `STARTING` | JVM or process launching |
| `AVAILABLE` | Ready and accepting connections |
| `INGAME` | Active with players in a game |
| `STOPPING` | Shutdown in progress |
| `CLEANUP` | Process ended, cleaning up resources |

## Runtime Environment Variables

Inside a running server, access server info without the API via `SimpleCloudRuntime`:

<CodeGroup>
```java Java
import app.simplecloud.api.runtime.SimpleCloudRuntime;

String serverId    = SimpleCloudRuntime.serverId();       // SIMPLECLOUD_UNIQUE_ID
String groupName   = SimpleCloudRuntime.groupName();      // SIMPLECLOUD_GROUP
String numericalId = SimpleCloudRuntime.numericalId();    // SIMPLECLOUD_NUMERICAL_ID
String serverName  = SimpleCloudRuntime.serverName();     // "Lobby-1" or serverId fallback
```

```kotlin Kotlin
import app.simplecloud.api.runtime.SimpleCloudRuntime

val serverId    = SimpleCloudRuntime.serverId()       // SIMPLECLOUD_UNIQUE_ID
val groupName   = SimpleCloudRuntime.groupName()      // SIMPLECLOUD_GROUP
val numericalId = SimpleCloudRuntime.numericalId()    // SIMPLECLOUD_NUMERICAL_ID
val serverName  = SimpleCloudRuntime.serverName()     // "Lobby-1" or serverId fallback
```
</CodeGroup>

You can also read the raw environment variables directly:

<CodeGroup>
```java Java
String group      = System.getenv("SIMPLECLOUD_GROUP");
String uniqueId   = System.getenv("SIMPLECLOUD_UNIQUE_ID");
String numId      = System.getenv("SIMPLECLOUD_NUMERICAL_ID");
```

```kotlin Kotlin
val group      = System.getenv("SIMPLECLOUD_GROUP")
val uniqueId   = System.getenv("SIMPLECLOUD_UNIQUE_ID")
val numId      = System.getenv("SIMPLECLOUD_NUMERICAL_ID")
```
</CodeGroup>
