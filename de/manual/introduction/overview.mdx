Mit SimpleCloud kannst du ein Minecraft-Servernetzwerk auf einer oder mehreren Maschinen betreiben. Über das Dashboard oder die CLI erstellst und steuerst du Server und siehst ihren Status an einem zentralen Ort.

## Erste Schritte

Öffne das SimpleCloud Dashboard und melde dich an. Der Einrichtungsassistent stellt dir den Befehl bereit, der SimpleCloud auf deiner ersten Maschine installiert und sie mit deinem Netzwerk verbindet.

<Card title="SimpleCloud installieren" icon="download" href="/de/manual/setup/installation">
  Verbinde deine erste Maschine und erstelle deinen ersten Server.
</Card>

## Funktionsweise deiner Server wählen

- Eine **Servergruppe** erstellt austauschbare Server aus gemeinsamen Einstellungen und Dateien. Verwende Gruppen für Proxys, Lobbys und Spielmodi, die mehrere identische Server oder automatische Skalierung benötigen können.
- Ein **persistenter Server** ist ein benannter Server, der seine eigene Welt und seine eigenen Dateien behält. Verwende ihn für einen langfristig betriebenen Server wie einen SMP- oder Build-Server.
- Ein **Serverhost** ist eine Maschine, auf der SimpleCloud deine Minecraft-Server ausführt. Füge einen weiteren Serverhost hinzu, wenn du eine weitere Maschine verwenden möchtest.
