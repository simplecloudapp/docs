Nutze SimpleCloud, wenn du Server-Gruppen erstellen, persistente Server online halten, mehrere Serverhosts verbinden und dein Netzwerk verwalten möchtest, ohne jede Maschine von Hand zu pflegen.

## Für wen ist das?

- **Netzwerk-Betreiber**, die automatisches Scaling basierend auf Spielerzahlen wollen
- **Server-Administratoren**, die ein zentrales Dashboard zur Verwaltung mehrerer Server benötigen
- **Jeder**, der mehr als einen Minecraft-Server betreibt und diese zusammenarbeiten lassen möchte

## Was kannst du mit SimpleCloud machen?

- **Server-Gruppen erstellen**, die automatisch hochskalieren wenn Spieler beitreten und herunterskalieren wenn sie gehen
- **Persistente Server einrichten** für Spielmodi wie Skyblock oder SMP, die ihre Weltdaten behalten
- **Alles über ein Dashboard verwalten** - Gruppen erstellen, Logs anzeigen, Performance überwachen
- **Mehrere Maschinen verbinden**, um Server über deine Infrastruktur zu verteilen
- **Offizielle Plugins installieren** für Routing, Befehle, Schilder, NPCs, Platzhalter und Benachrichtigungen

## Wichtige Features

- **Auto-Scaling** - Server starten und stoppen basierend auf Spielerzahlen
- **Dashboard** - Web-Interface zur Verwaltung deines gesamten Netzwerks
- **CLI** - Kommandozeilen-Tool für lokale und Remote-Verwaltung
- **Plugins** - Offizielle Erweiterungen für Proxy-Routing, In-Game-Verwaltung und Navigation
- **Multi-Root-Support** - Verbinde mehrere Serverhosts und synchronisiere gemeinsame Dateien
