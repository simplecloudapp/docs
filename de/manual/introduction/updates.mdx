## Versionsprüfungen

SimpleCloud-Komponenten und die CLI können prüfen, ob neuere Releases verfügbar sind. Die CLI fordert dich zum Update auf, wenn sie zu weit hinter der neuesten Version liegt.

- Nutze `simplecloud upgrade cli`, um die CLI selbst zu aktualisieren.
- Nutze `simplecloud upgrade`, wenn die CLI unterstützte installierte Targets aktualisieren soll.
- Prüfe Komponenten-Neustarts, bevor du Produktionshosts aktualisierst.
- Sichere Konfigurationen und Templates, bevor du Runtime-Komponenten änderst.

<Note>
  Die CLI fordert dich zum Update auf, wenn sie mehr als 5 Versionen hinter der neuesten Version liegt.
</Note>

## Auswirkungen im Betrieb

Updates können SimpleCloud-Komponenten neu starten. Plane sie wie jede andere Infrastrukturänderung:

- Aktualisiere nach Möglichkeit zuerst einen Serverhost.
- Prüfe, ob Serverstart und Shutdown weiterhin funktionieren.
- Rolle dasselbe Update danach auf die übrigen Hosts aus.
- Beobachte Dashboard-Status und Serverhost-Logs während des Rollouts.

## Manuelle Updates

Wenn du Updates lieber manuell auslösen möchtest, verwende den Upgrade-Befehl:

```bash
simplecloud upgrade
```

Ohne Targets aktualisiert dieser Befehl die CLI und alle installierten Komponenten. Du kannst auch bestimmte Targets aktualisieren:

```bash
simplecloud upgrade [targets..]
```

Targets können `cli`, Component-IDs oder Versions-Pins wie `serverhost@1.2.3` sein.

<Note>
  `simplecloud update` funktioniert weiterhin als Alias für `simplecloud upgrade`.
</Note>

## CLI aktualisieren

Die CLI selbst kann separat aktualisiert werden mit:

```bash
simplecloud upgrade cli
```

Dieser Befehl prüft auf eine neuere CLI-Version, lädt sie herunter und ersetzt deine aktuelle Installation. Verwende `simplecloud upgrade cli --cli-force`, um die aktuelle CLI-Version erneut zu installieren, auch wenn sie bereits aktuell ist.
