## CLI aktualisieren

Die CLI informiert dich, wenn eine neue Version verfügbar ist, aktualisiert sich aber nicht automatisch. Führe zum Installieren der neuesten Version Folgendes aus:

```bash
sc upgrade cli
```

Der Befehl ersetzt die CLI durch die neueste Version. Er startet weder den Serverhost noch Minecraft-Server neu.

Führe anschließend `sc --version` aus, um die installierte Version zu bestätigen.

## Automatische Serverhost-Updates

SimpleCloud weist jedem Serverhost automatisch die neueste Version zu. Weicht die zugewiesene von der installierten Version ab, lädt der Serverhost das Update herunter und startet sich neu.

Der Neustart betrifft nur den Serverhost-Prozess. Die Minecraft-Server laufen weiter, weil sie in eigenen Prozessen ausgeführt werden.

Automatische Updates aktualisieren weder die CLI noch Minecraft-Serversoftware oder Plugins. Aktualisiere diese getrennt.

## Serverhost sofort aktualisieren

Normalerweise musst du den Serverhost nicht selbst aktualisieren.

Führe den folgenden Befehl in deinem SimpleCloud-Installationsverzeichnis aus, um ein verfügbares Update sofort zu installieren:

```bash
sc restart --update
```

<Warning>
  Dieser Befehl aktualisiert den Serverhost und startet ihn neu. Führe ihn in einem Wartungsfenster aus. Sofern du diese Auswahl nicht bereits gespeichert hast, fragt SimpleCloud, ob auch die Minecraft-Server auf diesem Serverhost gestoppt werden sollen.
</Warning>

Prüfe nach Abschluss des Befehls, ob der Serverhost läuft:

```bash
sc status serverhost
```

Wenn der Serverhost nicht startet, prüfe seine Logs:

```bash
sc logs serverhost
```

Behebe das gemeldete Problem und führe anschließend `sc start serverhost` aus, um ihn wieder zu starten.

## Weitere Updateoptionen

<AccordionGroup>
  <Accordion title="Updates ohne Neustart herunterladen">
    Verwende `sc upgrade`, um die CLI und alle installierten SimpleCloud-Komponenten zu aktualisieren, oder `sc upgrade serverhost`, um nur das Serverhost-Update herunterzuladen.

    ```bash
    sc upgrade
    sc upgrade serverhost
    ```

    Diese Befehle starten laufende Komponenten nicht neu. Starte den Serverhost neu, sobald du seine neue Version verwenden möchtest.
  </Accordion>

  <Accordion title="Bestimmte Serverhost-Version installieren">
    Lade zum Testen oder Zurücksetzen die gewünschte Version herunter:

    ```bash
    sc upgrade serverhost@<version>
    ```

    Der Befehl startet den Serverhost nicht neu. Führe `sc restart serverhost` aus, sobald du die ausgewählte Version verwenden möchtest.
  </Accordion>

  <Accordion title="CLI-Update reparieren">
    Wenn deine CLI-Installation für deinen Benutzer nicht beschreibbar ist, führe `sudo sc upgrade cli` aus. Wenn die Installation beschädigt, aber bereits aktuell ist, installiere sie mit folgendem Befehl neu:

    ```bash
    sc upgrade cli --cli-force
    ```

    Wenn die CLI mehrere Versionen zurückliegt, kann ein Update erforderlich sein, bevor du andere Befehle ausführen kannst.
  </Accordion>
</AccordionGroup>
