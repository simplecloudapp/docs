---
title: "CLI"
description: "Richte SimpleCloud über dein Terminal ein und verwalte es dort"
---

Mit der SimpleCloud CLI kannst du einen Serverhost einrichten und dein Netzwerk über das Terminal verwalten. Verwende sie, um die SimpleCloud-Installation auf der aktuellen Maschine zu steuern oder Gruppen und Minecraft-Server in deinem gesamten Netzwerk zu verwalten.

<Tip>
  Führe `sc --help` aus, um alle Befehle anzuzeigen. Mit `sc <command> --help` erhältst du Hilfe zu einem bestimmten Befehl.
</Tip>

## CLI installieren

Führe den Installer auf der Maschine aus, die SimpleCloud hosten soll:

```bash
curl -fsSL https://get.simplecloud.app | bash
```

Prüfe anschließend, ob die CLI verfügbar ist:

```bash
sc --version
```

Folge für die vollständige Ersteinrichtung der [Installationsanleitung](/de/manual/setup/installation).

## Serverhost einrichten

Starte den Einrichtungsassistenten:

```bash
sc setup
```

Der Assistent meldet dich an, verbindet die Maschine mit deinem Netzwerk und installiert den Serverhost. Anschließend kannst du SimpleCloud über die CLI oder das Dashboard verwalten.

## SimpleCloud auf dieser Maschine verwalten

Verwende diese Befehle, um die lokale Installation zu steuern:

| Aufgabe | Befehl |
| --- | --- |
| SimpleCloud starten | `sc start` |
| SimpleCloud stoppen | `sc stop` |
| SimpleCloud neu starten | `sc restart` |
| Status prüfen | `sc status` |
| Serverhost-Logs anzeigen | `sc logs serverhost` |
| Serverhost-Konsole öffnen | `sc attach serverhost` |

<Note>
  Lokale Befehle wie `sc start` verwalten SimpleCloud auf der aktuellen Maschine. Befehle unter `sc server` verwalten Minecraft-Server in deinem Netzwerk.
</Note>

## Gruppen und Server verwalten

Erstelle mit dem interaktiven Assistenten eine Servergruppe:

```bash
sc group create
```

Danach kannst du einen Server starten und die laufenden Server anzeigen:

```bash
sc group start lobby
sc server list
```

Verwende diese Befehle für häufige Serveraufgaben:

```bash
sc server info lobby 1
sc server logs lobby 1 --follow
sc server stop lobby 1
```

Die vollständigen Abläufe findest du unter [Servergruppen](/de/manual/setup/server-groups) und [Server](/de/manual/setup/servers).

## SimpleCloud aktualisieren

Aktualisiere die CLI und die installierten SimpleCloud-Komponenten mit einem Befehl:

```bash
sc upgrade
```

Wenn eine installierte Komponente erneut heruntergeladen werden muss, führe Folgendes aus:

```bash
sc repair
```

## Anmelden

Führe `sc login` aus, wenn du dich erneut anmelden musst. Mit `sc whoami` prüfst du das aktuelle Konto und mit `sc logout` meldest du dich ab.

## Zwischen Netzwerken wechseln

Die CLI speichert jedes Netzwerk als Context und sendet Netzwerkbefehle an den aktiven Context. Bei der Einrichtung wird dein erster Context automatisch erstellt.

```bash
sc context list
sc context use <name>
```

Führe `sc context add` aus, um die CLI mit einem weiteren Netzwerk zu verbinden.

## Weiteren Serverhost hinzufügen

Installiere die CLI auf der neuen Maschine und führe Folgendes aus:

```bash
sc serverhost add
```

Folge für den vollständigen Ablauf der Anleitung [SimpleCloud auf mehreren Maschinen ausführen](/de/manual/setup/multi-root).

## Weitere Befehle entdecken

Die CLI unterstützt außerdem Templates, persistente Server, mehrere Contexts und erweiterte Installationsoptionen. Für diese Abläufe gibt es eigene Anleitungen. Die integrierte Hilfe der CLI zeigt dir jederzeit die aktuelle Befehlssyntax:

```bash
sc group --help
sc server --help
sc persistent-server --help
```

Mehr dazu erfährst du unter [Templates](/de/manual/setup/templates) und [Persistente Server](/de/manual/setup/persistent-servers).
