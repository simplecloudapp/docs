<AccordionGroup>
  <Accordion title="Was ist SimpleCloud?">
    SimpleCloud ist ein Management-System für Minecraft-Server-Netzwerke mit Auto-Scaling, Dashboard und CLI.

    Mehr erfahren in der [Übersicht](/de/manual/introduction/overview).
  </Accordion>

  <Accordion title="Welche Minecraft-Versionen werden unterstützt?">
    SimpleCloud kann Java-Serverprozesse ausführen. Eingebaute Configurators fokussieren gängige Setups mit Paper, Spigot, Velocity, BungeeCord und Waterfall; andere Software kann eigene Templates und Configurators benötigen.

    Blueprints für gängige Plattformen findest du in der [Gruppen-Dokumentation](/de/manual/setup/server-groups).
  </Accordion>

  <Accordion title="Brauche ich einen dedizierten Server?">
    SimpleCloud läuft auf jedem Linux-System oder macOS (Entwicklung). Für Produktion wird ein dedizierter Server oder VPS empfohlen.

    Siehe [Installation](/de/manual/setup/installation) für Details.
  </Accordion>

  <Accordion title="Wie funktioniert Auto-Scaling?">
    Gruppen starten automatisch Server wenn Spieler beitreten und fahren inaktive Server herunter. Du konfigurierst Mindest-/Höchstzahlen und der Controller verwaltet den Rest.

    Mehr unter [Gruppen](/de/manual/setup/server-groups).
  </Accordion>

  <Accordion title="Kann ich meine Weltdaten behalten?">
    Ja - verwende einen [Persistenten Server](/de/manual/setup/persistent-servers) anstelle einer Gruppe. Diese behalten ihre Daten zwischen Neustarts.
  </Accordion>

  <Accordion title="Was ist der Unterschied zwischen Plugins und Droplets?">
    Plugins laufen innerhalb von Minecraft-Servern für In-Game-Features. Droplets sind unabhängige Dienste für Infrastruktur-Aufgaben.

    Starte mit der [Plugin-Übersicht](/de/manual/plugin/overview).
  </Accordion>

  <Accordion title="Wie aktualisiere ich SimpleCloud?">
    Nutze `simplecloud upgrade cli` für die CLI und `simplecloud upgrade` für unterstützte installierte Targets. Die CLI weist dich darauf hin, wenn sie zu weit hinter der neuesten Version liegt.

    Mehr unter [Updates](/de/manual/introduction/updates).
  </Accordion>
</AccordionGroup>
