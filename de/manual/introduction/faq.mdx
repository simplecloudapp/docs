title: "FAQ"
description: "Antworten auf häufige Fragen zur Einrichtung und Verwendung von SimpleCloud"
---

<AccordionGroup>
  <Accordion title="Was ist SimpleCloud?">
    Mit SimpleCloud kannst du ein Minecraft-Servernetzwerk über ein einziges
    Dashboard oder den Befehl `sc` einrichten und verwalten.

    In der [SimpleCloud-Übersicht](/de/manual/introduction/overview) erfährst du,
    wie dein Netzwerk organisiert wird.
  </Accordion>

  <Accordion title="Wo soll ich anfangen?">
    Beginne mit der [Installationsanleitung](/de/manual/setup/installation). Sie
    führt dich von der Anmeldung im Dashboard bis zur Verbindung deines ersten
    Serverhosts.
  </Accordion>

  <Accordion title="Soll ich eine Servergruppe oder einen persistenten Server erstellen?">
    Verwende eine **Servergruppe**, wenn alle Server dieselbe Einrichtung teilen
    sollen und ihre lokalen Dateien nach dem Stoppen nicht erhalten bleiben müssen.
    Gruppen eignen sich gut für Lobbys, Minigames und Proxys.

    Verwende einen **persistenten Server** für einen benannten Server, der seine
    Dateien behält, beispielsweise einen SMP-, Skyblock- oder Build-Server.

    Vergleiche die Optionen unter [Servergruppen](/de/manual/setup/server-groups)
    und [Persistente Server](/de/manual/setup/persistent-servers).
  </Accordion>

  <Accordion title="Welche Betriebssysteme kann ich verwenden?">
    Dein Serverhost kann unter Linux oder macOS laufen. Linux wird für den
    Produktivbetrieb empfohlen, während sich macOS für lokale Tests eignet.
    Windows-Serverhosts werden noch nicht unterstützt.

    Du kannst das Web-Dashboard von einem anderen Gerät aus verwenden.

    Die Systemanforderungen findest du in der
    [Installationsanleitung](/de/manual/setup/installation).
  </Accordion>

  <Accordion title="Welche Minecraft-Serversoftware kann ich verwenden?">
    Wähle eine der Softwareoptionen aus, die das Dashboard anbietet. Wenn deine Software nicht aufgeführt ist, wähle **Custom** und fülle die erforderlichen Felder aus.

    Folge den Schritten zum Erstellen einer [Servergruppe](/de/manual/setup/server-groups#servergruppe-erstellen)
    oder eines [persistenten Servers](/de/manual/setup/persistent-servers#persistenten-server-erstellen).
  </Accordion>

  <Accordion title="Benötige ich fortgeschrittene technische Kenntnisse?">
    Für die grundlegende Einrichtung reichen wenige Terminalkenntnisse. Du
    solltest ein Terminal öffnen und den vom Dashboard bereitgestellten Befehl
    ausführen können. Für weitere Anpassungen brauchst du möglicherweise
    Kenntnisse der verwendeten Minecraft-Serversoftware.
  </Accordion>

  <Accordion title="Wo erhalte ich Hilfe?">
    Tritt dem [SimpleCloud Discord](https://discord.simplecloud.app) bei, um Hilfe
    von der Community zu erhalten.
  </Accordion>
</AccordionGroup>
