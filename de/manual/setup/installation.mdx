---

Der Einstieg in SimpleCloud erfordert nur wenige Schritte. Das Dashboard führt dich durch den gesamten Prozess - diese Seite bietet einen Überblick darüber, was dich erwartet.

## Konto erstellen

<Steps>
  <Step title="Dashboard öffnen">
    Gehe zum [SimpleCloud Dashboard](https://dash.simplecloud.app)
  </Step>
  <Step title="Anmelden">
    Erstelle ein Konto oder melde dich an mit einer der folgenden Optionen:

    - **Magic Link** - Gib deine E-Mail ein und erhalte einen Login-Link
    - **SSO** - Melde dich mit Google, Discord oder GitHub an

  </Step>
</Steps>

## Netzwerk erstellen oder beitreten

Nach der Anmeldung wähle, wie du starten möchtest:

<Tabs>
  <Tab title="Neues Netzwerk erstellen">
    1. Gib einen Namen für dein Netzwerk ein (z.B. "Mein Minecraft Netzwerk")
    2. Der URL-Slug wird automatisch generiert, kann aber angepasst werden
    3. Optional eine Beschreibung hinzufügen
    4. Klicke auf **Netzwerk erstellen**

    Der Setup-Assistent führt dich dann durch die Installation der CLI und die Verbindung deines ersten Server Hosts.

  </Tab>
  <Tab title="Bestehendem Netzwerk beitreten">
    1. Füge den Einladungscode ein, den du erhalten hast
    2. Klicke auf **Netzwerk beitreten**
  </Tab>
</Tabs>

## CLI installieren

Der Setup-Assistent zeigt dir den Installationsbefehl an. Kopiere ihn einfach und führe ihn in deinem Terminal aus.

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    /bin/bash -c "$(curl -fsSL https://get.simplecloud.app)"
    ```

    Überprüfe die Installation:

    ```bash
    simplecloud --version
    ```

  </Tab>
  <Tab title="Windows">
    <Note>
      Der CLI-Installer unterstützt Windows noch nicht. Nutze Linux für
      Produktion oder macOS für lokale Tests.
    </Note>
  </Tab>
</Tabs>

## Server Host verbinden

Ein Server Host ist die Maschine, die deine Minecraft-Server ausführen wird.

<Steps>
  <Step title="Setup-Befehl ausführen">
    Das Dashboard zeigt einen Setup-Befehl mit deinem eindeutigen Code an. Kopiere und führe ihn auf deinem Server aus:

    ```bash
    simplecloud setup --code=DEIN_CODE
    ```

  </Step>
  <Step title="Auf Setup warten">
    Das Setup wird:
    - Prüfen, ob alle Anforderungen installiert sind
    - Notwendige Komponenten herunterladen
    - Deine Maschine als Server Host registrieren
  </Step>
  <Step title="Fertig">
    Nach Abschluss erkennt das Dashboard automatisch deinen Server Host und leitet dich zum Haupt-Dashboard weiter.
  </Step>
</Steps>

## Teammitglieder einladen

Um andere zu deinem Netzwerk hinzuzufügen:

1. Gehe zu **Einstellungen** → **Mitglieder**
2. Klicke auf **Mitglied einladen**
3. Gib ihre E-Mail ein und wähle ihre Rolle
