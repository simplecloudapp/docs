Installiere SimpleCloud über das Dashboard. Nach Abschluss der Einrichtung erkennt das Dashboard deinen Serverhost automatisch und öffnet dein Netzwerk.

## Voraussetzungen

Du benötigst eine Linux- oder macOS-Maschine mit `curl` und Internetzugang. Verwende Linux für einen Serverhost im Produktivbetrieb. macOS eignet sich für lokale Tests. Windows wird noch nicht unterstützt.

Führe die Einrichtung mit einem Benutzerkonto aus, das im gewählten Installationsverzeichnis Dateien erstellen darf. Unter Linux benötigt das Konto außerdem `sudo`-Zugriff, falls die Einrichtung fehlende Software installieren muss.

## Ersten Serverhost verbinden

<Steps>
  <Step title="Im Dashboard anmelden">
    Öffne das [SimpleCloud Dashboard](https://dash.simplecloud.app) und melde dich an.
  </Step>

  <Step title="Netzwerk erstellen oder ihm beitreten">
    Erstelle ein Netzwerk oder tritt einem bestehenden Netzwerk mit einem Einladungscode bei. Wenn dein Netzwerk noch keinen Serverhost hat, öffnet das Dashboard den Einrichtungsassistenten.
  </Step>

  <Step title="Serverhost konfigurieren">
    Wähle das Betriebssystem aus, gib einen eindeutigen Namen ein und lege fest, wie viel Arbeitsspeicher SimpleCloud verwenden darf.

    Das Speicherlimit ist die Kapazität, die Minecraft-Servern auf dieser Maschine zur Verfügung steht. Lasse daher genügend Arbeitsspeicher für das Betriebssystem frei. Wähle Java 21 oder eine neuere Version aus. Die Einrichtung installiert die ausgewählten Java-Versionen und weitere erforderliche Software.
  </Step>

  <Step title="Einrichtungsbefehl ausführen">
    Öffne auf der Maschine ein Terminal und wechsle in das Verzeichnis, das die Installation enthalten soll. Der Befehl installiert SimpleCloud dort in einem Ordner namens `simplecloud`.

    Führe den im Dashboard angezeigten Befehl aus und befolge alle Aufforderungen im Terminal.

    <Warning>
      Der Befehl enthält einen temporären Anmeldecode. Teile ihn nicht und speichere ihn nicht in Skripten oder Dokumentation.
    </Warning>
  </Step>

  <Step title="Einrichtung abschließen">
    Warte, bis im Terminal **Setup complete** angezeigt wird. Das Dashboard erkennt den Serverhost automatisch und öffnet dein Netzwerk.
  </Step>
</Steps>

## Weiteren Serverhost hinzufügen

Öffne **Settings > Server Hosts**, wähle **Add Host** und führe den generierten Befehl auf der neuen Maschine aus. Verwende für jeden Serverhost einen neuen Befehl.

Wenn du mehrere Maschinen gemeinsam verwenden möchtest, fahre mit [SimpleCloud auf mehreren Maschinen ausführen](/de/manual/setup/multi-root) fort.

## Nur die CLI installieren

Der Dashboard-Befehl installiert die CLI bereits. Führe den folgenden Befehl aus, um nur die CLI auf einer Linux- oder macOS-Maschine zu installieren:

```bash
curl -fsSL https://get.simplecloud.app | bash
```

Prüfe, ob sie verfügbar ist:

```bash
sc --version
```

Dadurch wird die Maschine nicht als Serverhost verbunden. Verwende einen vom Dashboard generierten Einrichtungsbefehl, wenn sie Minecraft-Server ausführen soll.

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Die Shell findet sc nicht">
    Öffne ein neues Terminal und führe `sc --version` erneut aus.
  </Accordion>

  <Accordion title="Der Einrichtungsbefehl ist abgelaufen">
    Kehre zum Dashboard zurück und generiere einen neuen Befehl.
  </Accordion>

  <Accordion title="Die Einrichtung kann eine Voraussetzung nicht installieren">
    Stelle sicher, dass die Maschine Internetzugriff hat. Verwende unter Linux ein Konto, das `sudo` ausführen darf. Führe den Einrichtungsbefehl anschließend erneut aus.
  </Accordion>

  <Accordion title="Der Serverhost wird nicht im Dashboard angezeigt">
    Prüfe zuerst, ob im Terminal **Setup complete** angezeigt wurde. Falls ja, prüfe den Serverhost-Status und die aktuellen Logs:

    ```bash
    sc status serverhost
    sc logs serverhost
    ```

    Falls die Einrichtung nicht abgeschlossen wurde, behebe den im Terminal angezeigten Fehler, generiere im Dashboard einen neuen Befehl und versuche es im selben übergeordneten Verzeichnis erneut.
  </Accordion>
</AccordionGroup>
