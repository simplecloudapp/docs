## Im Dashboard starten

Das Dashboard ist der Hauptweg für das Onboarding. Es erstellt dein Netzwerk oder lässt dich einem Netzwerk beitreten, erzeugt den passenden Installationsbefehl für deine Maschine und erkennt den ersten Serverhost automatisch.

<Steps>
  <Step title="Dashboard öffnen">
    Gehe zum [SimpleCloud Dashboard](https://dash.simplecloud.app) und melde dich an oder erstelle ein Konto.

    Du kannst einen Magic Link oder einen der verfügbaren SSO-Anbieter verwenden.
  </Step>

  <Step title="Netzwerk erstellen oder beitreten">
    Erstelle ein neues Netzwerk, wenn du frisch startest, oder tritt einem bestehenden Netzwerk mit einer Einladung bei.

    Sobald das Netzwerk existiert, öffnet das Dashboard den Onboarding-Assistenten, wenn noch kein Serverhost verbunden ist.
  </Step>

  <Step title="Ersten Serverhost konfigurieren">
    Wähle Betriebssystem, Hostnamen, Speicherlimit, Java-Runtimes und ob SimpleCloud nach dem Setup starten soll.

    Linux ist für Produktion empfohlen. macOS eignet sich für lokale Tests. Windows-Setup ist noch nicht verfügbar.
  </Step>

  <Step title="Generierten Befehl ausführen">
    Kopiere den Befehl aus dem Dashboard und führe ihn auf der Maschine aus, die Minecraft-Server hosten soll.

    Der Befehl installiert die CLI, authentifiziert sich mit einem generierten Login-Code, registriert die Maschine als Serverhost und startet ihn auf Wunsch direkt.
  </Step>

  <Step title="Auf Erkennung warten">
    Lass das Dashboard geöffnet, während der Befehl läuft. Sobald der Serverhost verbunden ist, erkennt das Dashboard ihn und öffnet die Hauptansicht des Netzwerks.
  </Step>
</Steps>

## CLI später installieren

Nutze dies, wenn du die CLI auf einer Maschine brauchst, die nicht durch das komplette Onboarding geht.

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    curl -fsSL https://get.simplecloud.app | bash
    ```

    Prüfe die Installation:

    ```bash
    simplecloud --version
    ```

    Du kannst `sc` überall verwenden, wo die Dokumentation `simplecloud` zeigt.
  </Tab>

  <Tab title="Windows">
    <Note>
      Der CLI-Installer unterstützt Windows noch nicht. Nutze Linux für Produktion oder macOS für lokale Tests.
    </Note>
  </Tab>
</Tabs>

## Weiteren Serverhost hinzufügen

Füge nach dem Onboarding weitere Maschinen über das Dashboard hinzu, statt den ersten Setup-Befehl erneut zu verwenden.

<Steps>
  <Step title="Server-Hosts-Einstellungen öffnen">
    Öffne im Dashboard **Settings** und gehe zu **Server Hosts**.
  </Step>

  <Step title="Frischen Befehl erzeugen">
    Klicke auf **Add Host**. Das Dashboard erzeugt einen neuen Login-Code und einen Befehl für das aktuelle Netzwerk.
  </Step>

  <Step title="Auf der neuen Maschine ausführen">
    Kopiere den generierten Befehl auf die neue Maschine und führe ihn dort aus.

    Der Befehl sieht ungefähr so aus. Nutze aber den exakten Befehl aus deinem Dashboard, weil er Netzwerk, Login-Code und Hostnamen enthält:

    ```bash
    curl -fsSL https://get.simplecloud.app | bash ; ~/.bun/bin/simplecloud setup \
      --yes \
      --auto-install-deps \
      --start \
      --network dein-netzwerk \
      --code DEIN_LOGIN_CODE \
      --host-name host-2
    ```
  </Step>
</Steps>

## Teammitglieder einladen

So fügst du andere zu deinem Netzwerk hinzu:

1. Öffne **Settings** im Dashboard.
2. Gehe zu **Members**.
3. Klicke auf **Invite Member**.
4. Gib die E-Mail-Adresse ein und waehle eine Rolle.

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Das Dashboard kann keinen Login-Code erzeugen">
    Schließe den Dialog oder den Onboarding-Schritt, öffne ihn erneut und erzeuge einen frischen Befehl.

    Wenn das Problem bleibt, melde dich ab und wieder an, damit das Dashboard einen neuen authentifizierten Device-Code erstellen kann.
  </Accordion>

  <Accordion title="Der Installer kann keine Dateien herunterladen">
    Stelle sicher, dass die Maschine per HTTPS ins Internet kommt.

    Der Installer braucht ausgehenden Zugriff auf `get.simplecloud.app` und die Release-Download-Hosts, die SimpleCloud verwendet.
  </Accordion>

  <Accordion title="Der Serverhost erscheint nicht im Dashboard">
    1. Prüfe, ob der Befehl ohne Fehler abgeschlossen wurde.
    2. Prüfe mit `sc status serverhost`, ob der Serverhost läuft.
    3. Sieh dir die Serverhost-Logs mit `sc logs serverhost` an.
    4. Erzeuge einen frischen **Add Host**-Befehl, wenn der Login-Code alt war oder falsch kopiert wurde.
  </Accordion>

  <Accordion title="Setup scheitert beim Installieren von Abhängigkeiten">
    Führe den generierten Dashboard-Befehl unter Linux mit einem Benutzer aus, der benötigte Pakete installieren darf, oder installiere fehlende Abhängigkeiten manuell und versuche es erneut.

    Für lokale Tests auf macOS sollte der Befehl in einer normalen Shell mit Zugriff auf dein Benutzerprofil laufen.
  </Accordion>
</AccordionGroup>
