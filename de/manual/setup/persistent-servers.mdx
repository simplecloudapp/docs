## Voraussetzungen

Wenn du mehrere austauschbare Server oder automatische Skalierung benötigst, verwende stattdessen [Servergruppen](/de/manual/setup/server-groups).

Verbinde mindestens einen Serverhost und stelle sicher, dass er genügend Arbeitsspeicher für deinen Server hat.

<Warning>
  SimpleCloud verschiebt oder sichert die Dateien eines persistenten Servers nicht. Sichere Welten und andere wichtige Dateien selbst.
</Warning>

## Persistenten Server erstellen

<Steps>
  <Step title="Persistent Servers öffnen">
    Öffne **Persistent Servers** im Dashboard und klicke auf **Add Server**.
  </Step>

  <Step title="Server auswählen">
    Gib einen Namen ein, wähle **Server** oder **Proxy** aus und bestimme den Serverhost, der ihn ausführen soll.

    Namen dürfen bis zu 100 ASCII-Buchstaben, Ziffern, Unterstriche und Bindestriche (`[A-Za-z0-9_-]`) enthalten. Sie sind im Netzwerk unabhängig von Groß- und Kleinschreibung eindeutig, daher gelten `Survival-1` und `survival-1` als derselbe Name.
  </Step>

  <Step title="Software auswählen">
    Wähle die Serversoftware, Minecraft-Version und Java-Version aus.

    Wenn die Software nicht aufgeführt ist, wähle **Custom** und fülle die erforderlichen Felder aus. Siehe [Custom-Software](/de/manual/setup/custom-software).
  </Step>

  <Step title="Ressourcen festlegen">
    Wähle den Arbeitsspeicher und die maximale Spielerzahl aus. Proxys benötigen außerdem einen Startport.
  </Step>

  <Step title="Server erstellen">
    Prüfe die Konfiguration und klicke auf **Create Server**. SimpleCloud startet den Server automatisch, sofern du **Activate on creation** nicht deaktiviert hast.

    <Check>
      Wenn **Activate on creation** aktiviert ist, erreicht der Server den Status **Available** und seine Konsole zeigt die Start-Logs.
    </Check>
  </Step>
</Steps>

## Server starten und verwalten

Öffne den Server im Dashboard, um seinen Status, seine Konsole und seine Dateien anzuzeigen. Über sein Aktionsmenü kannst du ihn aktivieren, deaktivieren oder neu starten.

- **Enable** weist SimpleCloud an, den Server am Laufen zu halten. Wenn er stoppt, startet SimpleCloud ihn erneut.
- **Disable** stoppt den Server und lässt ihn gestoppt, bis du ihn wieder aktivierst.
- **Restart** stoppt und startet den Server, ohne seine Dateien zu löschen.

Du kannst den Server auch über den Schalter **Active** unter **Settings** aktivieren oder deaktivieren. Speichere alle weiteren Einstellungen, die du änderst. Wenn sich eine Änderung darauf auswirkt, wie der Server startet, starte ihn neu, um die neue Konfiguration anzuwenden.

Auf der Hauptseite **Settings** änderst du die Ressourcen, unter **Blueprint** die Software und Startkonfiguration. Unter **Deployment** weist du einen anderen Serverhost zu. Befolge davor die Migrationsschritte im nächsten Abschnitt.

Verwende den Tab **Files**, um Welt, Konfiguration und Plugins zu verwalten. Diese Dateien bleiben erhalten, wenn du den Server neu startest oder deaktivierst.

## Server auf einen anderen Serverhost verschieben

Wenn du den zugewiesenen Serverhost änderst, werden die Serverdateien nicht verschoben. Sichere und kopiere sie, bevor du den Server auf dem neuen Host startest.

<Steps>
  <Step title="Server deaktivieren">
    Deaktiviere den persistenten Server und warte, bis er gestoppt wurde.
  </Step>

  <Step title="Dateien kopieren">
    Der Pfad `running/persistent/<server-name>` gilt relativ zur SimpleCloud-Installation auf beiden Hosts. Kopiere das vollständige Verzeichnis, während der Server deaktiviert ist. Führe beispielsweise auf dem alten Host `rsync` aus und ersetze Benutzerkonto, Host, Installationspfad und Servernamen:

    ```bash
    rsync -a --numeric-ids \
      /srv/simplecloud/running/persistent/survival-1/ \
      simplecloud@new-host:/srv/simplecloud/running/persistent/survival-1/
    ```

    Führe die Kopie mit dem Benutzerkonto aus, dem die SimpleCloud-Installation gehört, damit Eigentümer und Berechtigungen auf dem Ziel passen.
  </Step>

  <Step title="Ziel prüfen">
    Führe auf dem neuen Serverhost `ls -ld /srv/simplecloud/running/persistent/survival-1` aus und prüfe mehrere enthaltene Dateien. Das Benutzerkonto des SimpleCloud-Dienstes muss das kopierte Verzeichnis lesen und beschreiben können.
  </Step>

  <Step title="Serverhost ändern">
    Öffne **Settings** > **Deployment**, wähle den neuen Serverhost aus und bestätige die Änderung.
  </Step>

  <Step title="Aktivieren und prüfen">
    Aktiviere den Server, tritt ihm bei und bestätige, dass seine Welten und seine Konfiguration vorhanden sind. Behalte die alte Kopie, bis diese Prüfung erfolgreich war.
  </Step>
</Steps>

<Warning>
  Wenn du den Server auf dem neuen Serverhost startest, bevor du seine Dateien kopiert hast, kann ein neues, leeres Serververzeichnis erstellt werden.
</Warning>

## Persistenten Server löschen

Öffne **Settings** > **Danger Zone** und folge den Aufforderungen zum Löschen. SimpleCloud stoppt den Server bei Bedarf und entfernt seine Konfiguration sowie den zugehörigen Blueprint. Die Serverdateien bleiben auf dem Serverhost erhalten.

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Der Server startet nicht">
    Stelle sicher, dass der Server aktiviert ist, sein Serverhost verbunden ist und der Host genügend freien Arbeitsspeicher hat. Prüfe anschließend die Serverkonsole auf Fehlermeldungen.
  </Accordion>

  <Accordion title="Die Welt ist nach einem Serverhost-Wechsel leer">
    Deaktiviere den Server. Kopiere sein Verzeichnis `running/persistent/<server-name>` vom alten auf den neuen Serverhost, aktiviere ihn anschließend und prüfe die Welt erneut.
  </Accordion>

  <Accordion title="Eine Einstellung wurde nicht übernommen">
    Speichere die Änderung und starte den Server neu. Prüfe seine Konsole, falls das Problem weiterhin besteht.
  </Accordion>
</AccordionGroup>
