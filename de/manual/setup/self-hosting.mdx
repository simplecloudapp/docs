---
title: "Self-hosting"
description: "Betreibe die SimpleCloud-Plattform mit Docker Compose auf deinem eigenen Server"
---

## Bevor du beginnst

Du brauchst:

- Einen Linux-Server mit Docker und Docker Compose 2.23.1 oder neuer. Die Ports 80 und 443 müssen aus dem Internet erreichbar sein.
- Eine Domain. Richte diese Subdomains auf den Server: `dash`, `auth`, `controller`, `nats` und `serverhosts`.

Die Beispiele verwenden `example.com`. In den Befehlen ersetzt du es nur einmal: im Setup-Befehl und in der `DOMAIN`-Zeile.

## Plattform starten

<Steps>
  <Step title="Konfiguration erstellen">
    Erstelle ein Verzeichnis für SimpleCloud und führe darin das Setup-Skript aus:

    ```bash
    mkdir simplecloud && cd simplecloud
    curl -fsSL https://raw.githubusercontent.com/simplecloudapp/simplecloud-manifest/main/self-hosting/setup.sh | bash -s -- example.com
    ```

    Das Skript lädt `compose.yaml` herunter, erstellt eine `.env`-Datei mit generierten Secrets und gibt die Callback-URLs für deine Domain aus. Halte `.env` privat.
  </Step>

  <Step title="Login-Anbieter hinzufügen">
    Nutzer melden sich mit Google, GitHub, Discord oder einem Link per E-Mail an. Richte mindestens eine Methode ein und trage ihre Zugangsdaten in `.env` ein. Die Login-Seite zeigt nur die Methoden, die du eingerichtet hast.

    <Tabs>
      <Tab title="Google">
        Erstelle in der [Google Cloud Console](https://console.cloud.google.com/apis/credentials) eine OAuth-Client-ID vom Typ **Webanwendung** mit dieser Weiterleitungs-URI:

        ```text
        https://auth.example.com/api/auth/callback/google
        ```

        Trage Client-ID und Secret in `.env` ein:

        ```bash .env
        GOOGLE_CLIENT_ID=...
        GOOGLE_CLIENT_SECRET=...
        ```
      </Tab>
      <Tab title="GitHub">
        Erstelle in deinen [GitHub-Entwicklereinstellungen](https://github.com/settings/developers) eine OAuth-App mit dieser Callback-URL:

        ```text
        https://auth.example.com/api/auth/callback/github
        ```

        Trage Client-ID und Secret in `.env` ein:

        ```bash .env
        GITHUB_CLIENT_ID=...
        GITHUB_CLIENT_SECRET=...
        ```
      </Tab>
      <Tab title="Discord">
        Erstelle im [Discord-Entwicklerportal](https://discord.com/developers/applications) eine Anwendung und füge unter **OAuth2** diese Weiterleitung hinzu:

        ```text
        https://auth.example.com/api/auth/callback/discord
        ```

        Trage Client-ID und Secret in `.env` ein:

        ```bash .env
        DISCORD_CLIENT_ID=...
        DISCORD_CLIENT_SECRET=...
        ```
      </Tab>
      <Tab title="E-Mail">
        Erstelle bei [Resend](https://resend.com/api-keys) einen API-Schlüssel und [verifiziere deine Domain](https://resend.com/domains). Trage den Schlüssel und eine Absenderadresse auf dieser Domain in `.env` ein:

        ```bash .env
        RESEND_API_KEY=...
        EMAIL_FROM=noreply@example.com
        ```

        Team-Einladungen werden ebenfalls per E-Mail verschickt. Richte das also ein, wenn du Mitglieder einladen willst.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Stack starten">
    ```bash
    docker compose up -d
    ```

    Caddy fordert die HTTPS-Zertifikate für deine Subdomains automatisch an. Öffne `https://dash.example.com`, melde dich an und erstelle ein Netzwerk.
  </Step>
</Steps>

## Serverhost verbinden

Führe diese Befehle auf jeder Maschine aus, auf der Minecraft-Server laufen sollen. Setze `DOMAIN` in der ersten Zeile. Die Befehle richten CLI und Serverhost vor dem Setup auf deinen Server aus.

```bash
DOMAIN=example.com

curl -fsSL https://get.simplecloud.app | bash

sc config controller-url set "https://controller.$DOMAIN"
sc config auth-url set "https://auth.$DOMAIN"
sc config dashboard-url set "https://dash.$DOMAIN"

mkdir -p ~/simplecloud
cat > ~/simplecloud/serverhost.properties <<EOF
CONTROLLER_URL=https://controller.$DOMAIN
NATS_URL=wss://nats.$DOMAIN:443
SERVERHOST_GATEWAY_URL=https://serverhosts.$DOMAIN
EOF

SIMPLECLOUD_NATS_URL="wss://nats.$DOMAIN:443" sc setup --install-dir ~/simplecloud
```

Das Setup öffnet dein Dashboard, damit du dich anmeldest und das Netzwerk auswählst.

## Aktualisieren

Lade die neuesten Images und starte den Stack neu:

```bash
docker compose pull
docker compose up -d
```
