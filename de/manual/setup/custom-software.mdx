## Custom-Software hinzufügen

Verwende **Custom** für Software, die nicht in der [Liste der unterstützten Software](https://simplecloud.app/supported-software) steht. Wenn du eine [Servergruppe](/de/manual/setup/server-groups) oder einen [persistenten Server](/de/manual/setup/persistent-servers) erstellst, wähle im Schritt **Software** die Option **Custom** und fülle diese Felder aus:

| Feld | Was du eingibst |
| --- | --- |
| **Source** | Lade eine `.jar`-Datei hoch oder gib ihre Download-URL oder ihren Dateipfad auf dem Serverhost ein. |
| **Software name** | Der Name der Software. SimpleCloud wählt damit die Plugins aus. |
| **Software version** | Die Version der Software. |
| **Game version** | Die Minecraft-Version. Nur beim Typ **Server** sichtbar. |

Wähle danach unter **Advanced** einen **Configurator**. Um diese Einstellungen später zu ändern, gehe zu **Settings > Software**.

## Anforderungen

- **JAR-Datei.** SimpleCloud startet die JAR mit Java 21. Java-Version, JVM-Optionen und Laufzeitargumente änderst du in der Karte **Java** unter **Settings > Software**.
- **Port.** Der Server muss auf seinem zugewiesenen Port lauschen, der als `%port%` in Configurators und als Umgebungsvariable `SIMPLECLOUD_PORT` verfügbar ist. SimpleCloud zeigt den Server als verfügbar an, sobald er auf diesem Port auf einen Status-Ping antwortet.
- **Configurator.** Der [Configurator](/de/manual/configuration/configurators) schreibt Port und Proxy-Einstellungen. Wähle eine Vorlage, die zu deiner Software passt, oder erstelle einen eigenen.
- **Plugins.** SimpleCloud-Plugins werden nur installiert, wenn der Softwarename eine unterstützte Plugin-Plattform ist, zum Beispiel `paper` oder `velocity`.

## Bedrock-Server

Bedrock-Server, die aus einer JAR starten, laufen über **Custom**:

- Registriere den Server selbst auf deinem Bedrock-Proxy. Die Proxy-Plugins von SimpleCloud übernehmen das nicht.
- Trage ihn in Server Connection unter `registration.ignore-server-groups-and-persistent-servers` ein, damit Velocity und BungeeCord keine Java-Spieler dorthin schicken.
- Verwende einen [eigenen Configurator](/de/manual/configuration/configurators), der `%port%` in die Konfiguration deines Servers schreibt.
- Um die [Cloud API](/de/developer/installation) zu verwenden, shade sie in dein eigenes Plugin.
