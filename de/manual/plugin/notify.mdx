## Plugin installieren

<Steps>
  <Step title="Plugin installieren">
    Lade Notify von [GitHub](https://github.com/simplecloudapp/simplecloud-plugins/releases) oder [Modrinth](https://modrinth.com/organization/simplecloud) herunter und lege die JAR in den Ordner `plugins/` des Proxy Templates.
  </Step>

  <Step title="Berechtigungen vergeben">
    Gib deinem Team die Berechtigungen für die Benachrichtigungen, die es bekommen soll, zum Beispiel `notify.state.server.available`. Mehr dazu unter [Berechtigungen](#berechtigungen).
  </Step>

  <Step title="Benachrichtigungen prüfen">
    Starte einen Proxy, betritt ihn und starte einen neuen Server.

    <Check>
      Du bekommst eine Nachricht, wenn der Server startet und wenn er verfügbar ist.
    </Check>
  </Step>
</Steps>

Alle Nachrichten kannst du in `plugins/simplecloud-notify/messages.yml` ändern.

## Benachrichtigungen

| Typ | Wird gesendet, wenn |
| --- | ------------------- |
| `server.starting` | ein Server startet |
| `server.available` | ein Server verfügbar ist |
| `server.stopping` | ein Server stoppt |
| `server.stopped` | ein Server gestoppt wurde |
| `group.created` | eine Gruppe erstellt wurde |
| `group.deleted` | eine Gruppe gelöscht wurde |
| `persistent-server.created` | ein persistenter Server erstellt wurde |
| `persistent-server.deleted` | ein persistenter Server gelöscht wurde |

Ein Spieler bekommt eine Benachrichtigung, wenn er die passende Berechtigung hat und sie nicht ausgeschaltet hat.

## Benachrichtigungen ein- und ausschalten

Jeder Spieler kann alle Benachrichtigungen oder einzelne Typen ein- und ausschalten:

```text
/scnotify disable
/scnotify enable server.starting
```

`/scnotify list` zeigt alle Typen, die du bekommen kannst, und ob sie an sind. Klicke auf einen Eintrag, um ihn umzuschalten.

Notify speichert die Auswahl in den SimpleCloud Properties des Spielers. Sie gilt deshalb auf jedem Proxy. Standardmäßig sind alle Benachrichtigungen an.

## Befehle

| Befehl | Beschreibung |
| ------ | ------------ |
| `/scnotify` oder `/scnotify help` | Zeigt die Befehle, die du verwenden kannst |
| `/scnotify list` | Zeigt deine Typen und ob sie an sind |
| `/scnotify enable [type]` | Schaltet alle Benachrichtigungen oder einen Typ ein |
| `/scnotify disable [type]` | Schaltet alle Benachrichtigungen oder einen Typ aus |
| `/scnotify set <player> <true\|false> [type]` | Schaltet Benachrichtigungen für einen anderen Spieler ein oder aus |
| `/scnotify reload config` | Lädt das Plugin neu |

## Berechtigungen

| Berechtigung | Beschreibung |
| ------------ | ------------ |
| `notify.state.server.starting` | Benachrichtigung, wenn ein Server startet |
| `notify.state.server.available` | Benachrichtigung, wenn ein Server verfügbar ist |
| `notify.state.server.stopping` | Benachrichtigung, wenn ein Server stoppt |
| `notify.state.server.stopped` | Benachrichtigung, wenn ein Server gestoppt wurde |
| `notify.state.group.created` | Benachrichtigung, wenn eine Gruppe erstellt wurde |
| `notify.state.group.deleted` | Benachrichtigung, wenn eine Gruppe gelöscht wurde |
| `notify.state.persistent-server.created` | Benachrichtigung, wenn ein persistenter Server erstellt wurde |
| `notify.state.persistent-server.deleted` | Benachrichtigung, wenn ein persistenter Server gelöscht wurde |
| `simplecloud.command.notify.help` | `/scnotify` und `/scnotify help` verwenden |
| `simplecloud.command.notify.reload.config` | `/scnotify reload config` verwenden |
| `simplecloud.command.notify.toggle.self` | `list`, `enable` und `disable` verwenden |
| `simplecloud.command.notify.toggle.other` | `/scnotify set` verwenden |

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Der Proxy lädt Notify nicht">
    Prüfe, ob `simplecloud-api` auf demselben Proxy installiert ist. Ohne die API startet Notify nicht.
  </Accordion>

  <Accordion title="Ein Spieler bekommt keine Benachrichtigungen">
    Prüfe, ob der Spieler die Berechtigung für den Typ hat. Führe dann als dieser Spieler `/scnotify list` aus, um zu sehen, ob der Typ ausgeschaltet ist.
  </Accordion>
</AccordionGroup>
