## Plugin installieren

<Steps>
  <Step title="Notify auf dem Proxy installieren">
    Lade Notify von [GitHub](https://github.com/simplecloudapp/notify-plugin/releases) herunter und lege die JAR-Datei im Ordner `plugins/` des Proxy-Templates ab. Die Standard-Templates enthalten `simplecloud-api` bereits. Füge es bei einem eigenen Template über die Einstellung **Plugins** des Ziels oder über die CLI hinzu.
  </Step>

  <Step title="Konfiguration erzeugen">
    Starte einmal einen passenden Proxy. Notify legt `plugins/simplecloud-notify/messages.yml` im Verzeichnis des laufenden Proxys an.
  </Step>

  <Step title="Konfiguration ins Template übernehmen">
    Kopiere bei einem Gruppen-Proxy `plugins/simplecloud-notify/messages.yml` vor dem Stoppen an denselben Pfad im Template. Änderungen, die nur im temporären Proxy-Verzeichnis liegen, gehen beim Stoppen verloren.

    Unter [Templates](/de/manual/setup/templates) findest du den vollständigen Ablauf.
  </Step>

  <Step title="Änderungen anwenden">
    Führe nach Änderungen an der Datei eines laufenden Proxys `/scnotify reload config` aus. Starte den Proxy neu, wenn du stattdessen die Datei im Template bearbeitet hast.

    <Check>
      Nach einem erfolgreichen Neuladen erscheint `Notify configuration was reloaded.`
    </Check>
  </Step>
</Steps>

## Benachrichtigungen

Notify empfängt Ereignisse über die Cloud API und kann Meldungen für diese Änderungen senden:

- Server wechselt zu `STARTING`, `AVAILABLE` oder `STOPPING`
- Server wurde gestoppt
- Gruppe wurde erstellt
- Gruppe wurde gelöscht

Setze eine einzelne Nachricht auf `null`, um sie zu deaktivieren. Mit `null` für den gesamten Abschnitt `notifications.server` oder `notifications.group` deaktivierst du die jeweilige Kategorie.

Teammitglieder können alle Meldungen für sich mit `/scnotify disable` ausschalten und mit `/scnotify enable` wieder einschalten. Notify speichert diese Einstellung in den SimpleCloud-Eigenschaften des Spielers, sodass sie proxyübergreifend gilt. Standardmäßig sind Benachrichtigungen aktiviert.

## Konfiguration

Notify verwendet MiniMessage für Textformatierungen. Die unterstützte Syntax findest du in der [MiniMessage-Dokumentation](https://docs.papermc.io/adventure/minimessage/).

Die erzeugte `messages.yml` enthält Nachrichtentexte, wiederverwendbare Variablen und Formatoptionen:

```yaml
version: "1"

format:
  date: "dd.MM.yyyy HH:mm:ss"

variables:
  prefix: "<color:#0EA5E9><bold>⚡</bold></color>"

notifications:
  hover:
    server: |-
      <#E2E8F0>Server information
      <br><#94A3B8>Time<#475569>: <#E2E8F0><time>
      <br><#94A3B8>State<#475569>: <#E2E8F0><state>
      <br><#94A3B8>Address<#475569>: <#E2E8F0><ip>:<port>
      <br><#94A3B8>Players<#475569>: <#E2E8F0><players>/<max>
    group: |-
      <#E2E8F0>Group information
      <br><#94A3B8>Time<#475569>: <#E2E8F0><time>

  server:
    starting: "<prefix> <#0EA5E9>Server <hover:show_text:'<notifications.hover.server>'><#F8FAFC><server></hover> is now starting."
    available: "<prefix> <#A3E635>Server <hover:show_text:'<notifications.hover.server>'><#F8FAFC><server></hover> is now available."
    stopping: "<prefix> <#F59E0B>Server <hover:show_text:'<notifications.hover.server>'><#F8FAFC><server></hover> is now stopping."
    stopped: "<prefix> <#DC2626>Server <hover:show_text:'<notifications.hover.server>'><#F8FAFC><server></hover> is now stopped."

  group:
    created: "<prefix> <#0EA5E9>Group <hover:show_text:'<notifications.hover.group>'><#F8FAFC><group></hover> was created."
    deleted: "<prefix> <#DC2626>Group <hover:show_text:'<notifications.hover.group>'><#F8FAFC><group></hover> was deleted."
```

## Platzhalter

### Serverbenachrichtigungen

| Platzhalter | Beschreibung |
| ----------- | ------------ |
| `<server>` | Gruppen- oder Serverbasisname |
| `<group>` | Gruppenname |
| `<id>` | Numerische ID mit vorangestelltem Leerzeichen, falls vorhanden |
| `<uuid>` | Server-UUID |
| `<state>` | Aktueller Serverstatus |
| `<ip>` | Server-IP-Adresse |
| `<port>` | Server-Port |
| `<players>` | Aktuelle Spielerzahl |
| `<max>` | Maximale Spielerzahl |
| `<time>` | Aktueller Zeitstempel im Format `format.date` |
| `<updated>` | Zeitstempel der letzten Aktualisierung im Format `format.date` |
| `<create_date>` | Erstellungszeitpunkt im Format `format.date` |

### Gruppenbenachrichtigungen

| Platzhalter | Beschreibung |
| ----------- | ------------ |
| `<group>` | Gruppenname |
| `<time>` | Aktueller Zeitstempel im Format `format.date` |

## Befehle

| Befehl | Beschreibung |
| ------ | ------------ |
| `/scnotify` oder `/scnotify help` | Verfügbare Befehle anzeigen |
| `/scnotify enable` | Benachrichtigungen wieder empfangen |
| `/scnotify disable` | Benachrichtigungen ausschalten, ohne Berechtigungen zu ändern |
| `/scnotify set <player> <true\|false>` | Benachrichtigungen für einen Online-Spieler ein- oder ausschalten |
| `/scnotify reload config` | `messages.yml` neu laden |

Der persönliche Schalter gilt für alle Notify-Meldungen. Die Ereignisberechtigungen bestimmen weiterhin, welche Kategorien ein aktivierter Spieler erhält.

## Berechtigungen

| Berechtigung | Beschreibung |
| ------------ | ------------ |
| `notify.state.server.starting` | Meldungen zu startenden Servern empfangen |
| `notify.state.server.available` | Meldungen zu verfügbaren Servern empfangen |
| `notify.state.server.stopping` | Meldungen zu stoppenden Servern empfangen |
| `notify.state.server.stopped` | Meldungen zu gestoppten Servern empfangen |
| `notify.state.group.created` | Meldungen zu erstellten Gruppen empfangen |
| `notify.state.group.deleted` | Meldungen zu gelöschten Gruppen empfangen |
| `simplecloud.command.notify.help` | `/scnotify` und `/scnotify help` verwenden |
| `simplecloud.command.notify.reload.config` | `messages.yml` neu laden |
| `simplecloud.command.notify.toggle.self` | Eigene Benachrichtigungen ein- oder ausschalten |
| `simplecloud.command.notify.toggle.other` | Benachrichtigungen eines anderen Online-Spielers ändern |

<Note>
  Notify prüft die Berechtigung für jede Meldung einzeln. Weise Teammitgliedern nur die Ereigniskategorien zu, die sie erhalten sollen.
</Note>

<Note>
  `notify.state.server.deleted` wird weiterhin als veralteter Alias für Meldungen zu gestoppten Servern akzeptiert.
</Note>

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Der Proxy kann Notify nicht laden">
    Prüfe, ob `simplecloud-api` auf demselben Proxy installiert und aktiviert ist. Notify benötigt das Plugin für SimpleCloud-Ereignisse und Spielereigenschaften.
  </Accordion>

  <Accordion title="Ein Teammitglied erhält keine Benachrichtigungen">
    Führe als betroffener Spieler `/scnotify enable` aus und weise dann die Berechtigung für jede gewünschte Ereigniskategorie zu. Sowohl der persönliche Schalter als auch die Ereignisberechtigung müssen die Meldung erlauben.
  </Accordion>

  <Accordion title="Nachrichtenänderungen verschwinden nach einem Neustart">
    Bearbeite `plugins/simplecloud-notify/messages.yml` im Proxy-Template oder kopiere die getestete Datei dorthin, bevor ein temporärer Gruppen-Proxy stoppt.
  </Accordion>
</AccordionGroup>
