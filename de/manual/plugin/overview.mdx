Plugins sind Server-seitige Erweiterungen, die innerhalb deiner Minecraft-Server laufen. Sie nutzen die Cloud API, um mit deiner Netzwerk-Infrastruktur zu interagieren.

## Offizielle Plugins

| Plugin | Plattform | Beschreibung |
|--------|-----------|--------------|
| [Server Connection](/de/manual/plugin/server-connection) | Proxy | Registriert Server und verwaltet Joins, Fallbacks und Hub-Befehle |
| [Cloud Command](/de/manual/plugin/cloud-command) | Proxy | In-Game Cloud-Management-Befehle |
| [Proxy Essentials](/de/manual/plugin/proxy-essentials) | Proxy | MOTD, Tablist, Joinstates, Layouts und Player Counts |
| [Notify](/de/manual/plugin/notify) | Proxy | Server- und Gruppen-Eventbenachrichtigungen |
| [Prefixes](/de/manual/plugin/prefixes) | Server | Spieler-Präfix-Verwaltung |
| [Signs](/de/manual/plugin/signs) | Server | Dynamische Schilder für Gruppen |
| [NPCs](/de/manual/plugin/npcs) | Server | NPC-Interaktionen, Hologramme und Servernavigation |
| [Placeholders](/de/manual/plugin/placeholders) | Server | PlaceholderAPI-Integration für Server und Gruppen |

## Plugins installieren

### Via Dashboard

Beim Erstellen oder Bearbeiten einer Gruppe kannst du Plugins aus den Plugin-Einstellungen hinzufügen. Suche nach Plugins und sie werden automatisch auf allen Servern dieser Gruppe installiert.

### Via CLI

```bash
# Plugins einer Gruppe auflisten
sc group plugin list lobby

# Plugin zu einer Gruppe hinzufügen
sc group plugin add lobby proxy-essentials

# Plugin zu einem persistenten Server hinzufügen
sc persistent-server plugin add spawn proxy-essentials

# Plugin von einer Gruppe entfernen
sc group plugin remove lobby proxy-essentials
```

Die optionale Plugin-Query kann ein Suchbegriff, ein Modrinth-Slug wie `mr:luckperms`, eine Spigot-ID wie `sp:28140` oder eine Plugin-URL sein.

### Manuell

Lege Plugin-JARs in den `plugins/` Ordner deines Templates:

```bash
cp mein-plugin.jar templates/lobby/plugins/
```

## Plugins vs Droplets

| | Plugins | Droplets |
|---|---------|----------|
| **Läuft auf** | Innerhalb des Minecraft-Servers | Unabhängiger Dienst |
| **Zweck** | In-Game Features | Infrastruktur-Aufgaben |
| **Beispiele** | Schilder, NPCs, Befehle | Spielerdaten, Resource Packs |

Für Infrastruktur-Level-Integrationen siehe die [Developer-Dokumentation](/de/developer/overview).
