## Plugins installieren

### Über das Dashboard

Beim Erstellen oder Bearbeiten einer Gruppe kannst du in den Plugin-Einstellungen nach Plugins suchen und sie hinzufügen. Neue Server der Gruppe starten mit den ausgewählten Plugins. Verwende bei einer bereits laufenden Gruppe nach dem Speichern **Hold to rolling restart**, um alle Instanzen nacheinander zu ersetzen.

### Über die CLI

```bash
# Plugins einer Gruppe auflisten
sc group plugin list lobby

# Plugin zu einer Proxy-Gruppe hinzufügen
sc group plugin add proxy proxy-essentials

# Plugin zu einem persistenten Proxy hinzufügen
sc persistent-server plugin add proxy-main proxy-essentials

# Plugin von einer Gruppe entfernen
sc group plugin remove proxy proxy-essentials
```

Als optionale Suchangabe kannst du einen Namen, einen Modrinth-Slug wie `mr:luckperms`, eine Spigot-ID wie `sp:28140` oder eine Plugin-URL verwenden.

### Manuell

Lege Plugin-JARs in den `plugins/`-Ordner deines Templates:

```bash
cp mein-plugin.jar templates/lobby/plugins/
```

## Plugins und Droplets

| | Plugins | Droplets |
|---|---------|----------|
| **Läuft auf** | Innerhalb eines Minecraft-Servers oder Proxys | Unabhängiger Dienst |
| **Zweck** | Funktionen im Spiel | Infrastrukturaufgaben |
| **Beispiele** | Schilder, NPCs, Befehle | Spielerdaten, Ressourcenpakete |

Mit der [Dokumentation zur Cloud API](/de/developer/overview) entwickelst du Minecraft-Plugins. Eine Anleitung zur Droplet-Entwicklung ist noch nicht verfügbar.
