Das NPCs-Plugin verbindet einen NPC eines unterstützten Anbieters mit einer SimpleCloud-Servergruppe oder einem persistenten Server. Es kann den NPC erstellen, den aktuellen Status in einem Hologramm anzeigen und Spieler per Klick mit einem verfügbaren Ziel verbinden.

Im üblichen Ablauf verwendest du `/scnpcs create`. Nutze `/scnpcs link`, wenn der NPC bereits in Citizens, FancyNpcs, MythicMobs oder ZNPCsPlus existiert.

## Unterstützte Software

| Serversoftware | Unterstützung |
| -------------- | ------------- |
| Paper und Forks | Ja |
| Spigot | Nein |

## Unterstützte NPC-Anbieter

| Anbieter | Mit `/scnpcs create` erstellen | Bestehenden NPC verknüpfen |
| -------- | ----------------------------- | --------------------------- |
| Citizens | Ja | Ja |
| FancyNpcs | Ja | Ja |
| ZNPCsPlus | Ja | Ja |
| MythicMobs | Nein | Ja |

Du benötigst mindestens einen unterstützten Anbieter. Das NPCs-Plugin deaktiviert sich beim Start, wenn es keinen findet.

<Warning>
  NPC-Definitionen, Anbieterdaten und Weltobjekte müssen zusammenbleiben. Am einfachsten betreibst du das Plugin auf einer persistenten Lobby. Für eine temporäre Servergruppe konfigurierst du die NPCs auf einem persistenten Staging-Server, stoppst ihn sauber und kopierst anschließend die Welt, `plugins/simplecloud-npc/` und die Anbieterdaten ins Gruppen-Template. Kopiere keine laufende Welt ins Template.
</Warning>

## Plugin installieren

<Steps>
  <Step title="Plugins installieren">
    Lade das NPCs-Plugin von [GitHub](https://github.com/simplecloudapp/npc-plugin/releases) und einen unterstützten NPC-Anbieter herunter. Lege beide JAR-Dateien im Ordner `plugins/` des Paper-Server-Templates ab. Die Standard-Templates enthalten `simplecloud-api` bereits. Füge es bei einem eigenen Template über die Einstellung **Plugins** des Ziels oder über die CLI hinzu.
  </Step>

  <Step title="NPC für ein Ziel erstellen">
    Starte den Server und stelle dich an die gewünschte Position. Wähle eine eindeutige ID und den Namen einer bestehenden SimpleCloud-Gruppe oder eines persistenten Servers. Führe für die Gruppe `Lobby` diesen Befehl aus:

    ```text
    /scnpcs create lobby-selector Lobby
    ```

    Sind mehrere Anbieter installiert, die NPCs erstellen können, gib den Anbieter an:

    ```text
    /scnpcs create lobby-selector Lobby citizens
    ```
  </Step>

  <Step title="Ergebnis prüfen">
    Führe `/scnpcs info lobby-selector` aus. Der Status sollte `complete` sein und der NPC ein zweizeiliges Hologramm haben. Ein Rechtsklick verbindet dich mit dem verfügbaren `Lobby`-Server, auf dem die wenigsten Spieler sind.
  </Step>
</Steps>

## Bestehenden NPC verknüpfen

Verwende die native Referenz des Anbieters, wenn der NPC bereits existiert:

```text
/scnpcs link lobby-selector citizens 12 Lobby
```

Der Befehl erstellt die SimpleCloud-ID `lobby-selector`, verknüpft den Citizens-NPC `12` und setzt `Lobby` als Ziel. Die Referenz unterscheidet sich je nach Anbieter; nutze die Befehlsvorschläge, um einen installierten Anbieter und NPC auszuwählen.

Das Anbieter-Plugin verwaltet verknüpfte NPCs weiterhin. `/scnpcs unlink lobby-selector` entfernt nur die SimpleCloud-Konfiguration und das Hologramm.

## Standardverhalten

Ein neuer oder verknüpfter NPC erhält:

- ein Hologramm `default` mit Zielname und Spielerzahl
- ein Hologramm `maintenance`, das das Ziel als nicht verfügbar anzeigt
- eine Rechtsklick-Aktion, die im Status `default` mit dem Ziel verbindet
- eine Rechtsklick-Nachricht im Status `maintenance`

Bei einer Gruppe wählt die Verbindungsaktion den `AVAILABLE`-Server mit den wenigsten Spielern. Bei einem persistenten Server verwendet sie dessen Registrierungsnamen auf dem Proxy.

## Befehle

Der Hauptbefehl ist als `/simplecloudnpcs`, `/scnpcs` und `/scnpc` verfügbar.

| Befehl | Beschreibung |
| ------ | ------------ |
| `/scnpcs help [topic]` | Hauptseite oder Hilfeseite zu `create`, `link`, `edit`, `target`, `hologram`, `action`, `pushback` oder `admin` anzeigen |
| `/scnpcs create <id> <target> [provider]` | NPC beim Anbieter an der eigenen Position erstellen und konfigurieren |
| `/scnpcs link <id> <provider> <reference> <target>` | Bestehenden NPC eines Anbieters verknüpfen |
| `/scnpcs list` | Konfigurierte NPCs auflisten |
| `/scnpcs info <id>` | Anbieter, Ziele, Hologramm, Aktionszahl und Konfigurationsstatus anzeigen |
| `/scnpcs edit <id>` | Bearbeitbare Bereiche anzeigen |
| `/scnpcs unlink <id>` | SimpleCloud-Konfiguration entfernen, aber Anbieter-NPC behalten |
| `/scnpcs delete <id>` | Konfiguration und bei verwalteten NPCs auch den Anbieter-NPC löschen |
| `/scnpcs placeholders` | Zielplatzhalter auflisten |
| `/scnpcs reload` | NPC-Definitionen und `messages.yml` neu laden |

<Warning>
  Wenn SimpleCloud den NPC erstellt hat, löscht `/scnpcs delete` auch den NPC beim Anbieter. Verwende `/scnpcs unlink`, wenn du ihn behalten möchtest.
</Warning>

## Ziele ändern

Ein NPC kann mehrere Ziele nacheinander prüfen und das erste mit einem verfügbaren Server verwenden.

```text
/scnpcs edit lobby-selector target list
/scnpcs edit lobby-selector target add BackupLobby
/scnpcs edit lobby-selector target remove Lobby
```

Ein NPC muss mindestens ein Ziel behalten. Bei Gruppen und persistenten Servern wird die Groß- und Kleinschreibung nicht beachtet. Ein Name ist ungültig, wenn er beide Ressourcentypen bezeichnet.

## Hologramm bearbeiten

Der Joinstate wählt das Hologramm-Layout aus. Verwende `default` für den Normalbetrieb und `maintenance`, wenn die Eigenschaft `joinstate` des Ziels auf `maintenance` steht.

```text
/scnpcs edit lobby-selector hologram line set default 1 <#38bdf8><bold><target_name>
/scnpcs edit lobby-selector hologram line add maintenance <#dc2626>Versuche es später erneut
/scnpcs edit lobby-selector hologram height 2.5
```

Zeilennummern beginnen bei `1`. `/scnpcs help hologram` zeigt die Befehle zum Aktivieren, Deaktivieren, Hinzufügen, Ändern und Entfernen.

### Zielplatzhalter

| Platzhalter | Beschreibung |
| ----------- | ------------ |
| `<target_name>` | Name der Gruppe oder des persistenten Servers |
| `<target_type>` | Ressourcentyp des Ziels |
| `<target_online_players>` | Aktuelle Spielerzahl |
| `<target_max_players>` | Maximale Spielerzahl |
| `<target_min_memory>` | Minimaler Arbeitsspeicher in MB |
| `<target_max_memory>` | Maximaler Arbeitsspeicher in MB |
| `<target_property:key>` | Eigene Zieleigenschaft `key` |
| `<target_id>` | ID des persistenten Servers |
| `<target_pretty_name>` | Anzeigename des persistenten Servers |
| `<target_motd>` | MOTD des persistenten Servers |

## Klickaktionen konfigurieren

Aktionen gelten jeweils für eine Interaktion und einen Joinstate. Unterstützt werden `RIGHT_CLICK`, `LEFT_CLICK`, `SHIFT_RIGHT_CLICK` und `SHIFT_LEFT_CLICK`.

Diese Befehle behalten die Standardaktion zum Verbinden bei und ergänzen Rückmeldungen für den Spieler:

```text
/scnpcs edit lobby-selector action join-target RIGHT_CLICK default true
/scnpcs edit lobby-selector action play-sound RIGHT_CLICK default block.note_block.pling
/scnpcs edit lobby-selector action send-message RIGHT_CLICK maintenance <#dc2626>Die Lobby wird gerade gewartet.
```

Das Plugin kann außerdem einen Spielerbefehl ausführen, den Spieler teleportieren, einen Titel anzeigen, ihn zu einem auf dem Proxy registrierten Server senden oder an eine externe Adresse übertragen. Die genauen Befehlsformen stehen unter `/scnpcs help action`.

`execute-command` unterstützt `<playername>` und `<playeruuid>` im konfigurierten Befehl.

## Berechtigungen

| Berechtigung | Beschreibung |
| ------------ | ------------ |
| `simplecloud.npcs.command` | Alle NPC-Verwaltungsbefehle verwenden; standardmäßig für Operatoren erlaubt |

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Das NPCs-Plugin deaktiviert sich beim Start">
    Installiere Citizens, FancyNpcs, MythicMobs oder ZNPCsPlus auf demselben Paper-Server und starte ihn neu. In der Konsole erscheint die Liste der verfügbaren Anbieter.
  </Accordion>

  <Accordion title="Create verlangt einen Anbieter">
    Mehrere installierte Anbieter können NPCs erstellen. Ergänze den Befehl um `citizens`, `fancynpcs` oder `znpcsplus`.
  </Accordion>

  <Accordion title="Das Ziel fehlt oder ist nicht eindeutig">
    Prüfe, ob die Gruppe oder der persistente Server existiert. Verwenden beide Ressourcentypen denselben Namen, musst du einen davon vor dem Erstellen oder Verknüpfen umbenennen.
  </Accordion>

  <Accordion title="Der NPC existiert, verbindet aber nicht mit einem Server">
    Führe `/scnpcs info <id>` aus und behebe einen unvollständigen Status. Für eine Gruppe muss mindestens ein Server den Status `AVAILABLE` haben. Ein persistenter Server muss aktiv und auf dem Proxy registriert sein.
  </Accordion>
</AccordionGroup>
