## Plugin installieren

<Steps>
  <Step title="Plugin installieren">
    Lade Cloud Command von [GitHub](https://github.com/simplecloudapp/simplecloud-plugins/releases) oder [Modrinth](https://modrinth.com/organization/simplecloud) herunter und lege die JAR in den Ordner `plugins/` des Proxy Templates.
  </Step>

  <Step title="Befehle prüfen">
    Starte einen Proxy, gib dir die Berechtigung `simplecloud.command.use` und führe `/cloud` aus.

    <Check>
      Das Hilfemenü zeigt alle Befehle, für die du eine Berechtigung hast.
    </Check>
  </Step>
</Steps>

Alle Nachrichten kannst du in `plugins/simplecloud-command/messages.yml` ändern.

## Befehle

Du kannst `/cloud`, `/sc` oder `/simplecloud` verwenden.

### Gruppen

| Befehl | Beschreibung |
| ------ | ------------ |
| `/cloud group list` | Zeigt alle Gruppen mit ihren Servern |
| `/cloud group info <group>` | Zeigt Typ, Arbeitsspeicher, maximale Spieler und laufende Server einer Gruppe |
| `/cloud group start <group> [count]` | Startet einen oder mehrere Server, maximal 50 auf einmal |
| `/cloud group stop <group> [id]` | Stoppt alle Server einer Gruppe oder nur den Server mit dieser numerischen ID |

### Server

| Befehl | Beschreibung |
| ------ | ------------ |
| `/cloud server list [group]` | Zeigt alle laufenden Server, optional nur von einer Gruppe |
| `/cloud server info <group> <id>` | Zeigt Status, Arbeitsspeicher und Spieler eines Servers |
| `/cloud server start <group>` | Startet einen neuen Server |
| `/cloud server stop <group> <id>` | Stoppt einen Server |

### Spieler

Als Ziel verwendest du `group` für eine Gruppe oder `ps` für einen persistenten Server.

| Befehl | Beschreibung |
| ------ | ------------ |
| `/cloud player list <group\|ps> <target>` | Zeigt die Spieler auf einem Ziel |
| `/cloud player info <player>` | Zeigt Server, Proxy, Spielzeit, ersten und letzten Join eines Spielers |
| `/cloud player send <player> <group\|ps> <target>` | Sendet einen Spieler zu einem Ziel |
| `/cloud player sendall <group\|ps> <target>` | Sendet alle Spieler zu einem Ziel |
| `/cloud player sendfrom <source> <group\|ps> <target>` | Sendet alle Spieler von einer Quelle zu einem Ziel |
| `/cloud player message <player> <message>` | Sendet einem Spieler eine Nachricht |

Die `<source>` bei `sendfrom` kann eine Gruppe, ein Server wie `Lobby-1` oder ein persistenter Server sein.

### Sonstiges

| Befehl | Beschreibung |
| ------ | ------------ |
| `/cloud reload` | Lädt das Plugin neu |

## Berechtigungen

| Berechtigung | Beschreibung |
| ------------ | ------------ |
| `simplecloud.command.use` | `/cloud` verwenden und das Hilfemenü sehen |
| `simplecloud.command.group.list` | `/cloud group list` verwenden |
| `simplecloud.command.group.info` | `/cloud group info` verwenden |
| `simplecloud.command.group.start` | `/cloud group start` verwenden |
| `simplecloud.command.group.stop` | `/cloud group stop` verwenden |
| `simplecloud.command.server.list` | `/cloud server list` verwenden |
| `simplecloud.command.server.info` | `/cloud server info` verwenden |
| `simplecloud.command.server.start` | `/cloud server start` verwenden |
| `simplecloud.command.server.stop` | `/cloud server stop` verwenden |
| `simplecloud.command.player.list` | `/cloud player list` verwenden |
| `simplecloud.command.player.info` | `/cloud player info` verwenden |
| `simplecloud.command.player.send` | `send`, `sendall` und `sendfrom` verwenden |
| `simplecloud.command.player.message` | `/cloud player message` verwenden |
| `simplecloud.command.reload` | `/cloud reload` verwenden |

Das Hilfemenü zeigt nur die Befehle, für die du eine Berechtigung hast.

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Der Proxy lädt Cloud Command nicht">
    Prüfe, ob `simplecloud-api` auf demselben Proxy installiert ist. Ohne die API startet Cloud Command nicht.
  </Accordion>

  <Accordion title="Ein Befehl fehlt im Hilfemenü">
    Gib dir die passende Berechtigung. Das Hilfemenü blendet Befehle aus, die du nicht verwenden darfst.
  </Accordion>

</AccordionGroup>
