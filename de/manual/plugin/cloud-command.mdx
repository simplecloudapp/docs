## Plugin installieren

<Steps>
  <Step title="Cloud Command auf dem Proxy installieren">
    Lade Cloud Command von [Modrinth](https://modrinth.com/plugin/cloud-command-plugin) herunter und lege die JAR-Datei im Ordner `plugins/` des Proxy-Templates ab. Die Standard-Templates enthalten `simplecloud-api` bereits. Füge es bei einem eigenen Template über die Einstellung **Plugins** des Ziels oder über die CLI hinzu.
  </Step>

  <Step title="Nachrichtendatei erzeugen">
    Starte einmal einen passenden Proxy. Cloud Command legt `plugins/simplecloud-command/messages.yml` im Verzeichnis des laufenden Proxys an.
  </Step>

  <Step title="Nachrichtendatei ins Template übernehmen">
    Kopiere bei einem Gruppen-Proxy `plugins/simplecloud-command/messages.yml` vor dem Stoppen an denselben Pfad im Template. Dateien, die nur im temporären Proxy-Verzeichnis liegen, gehen beim Stoppen verloren.

    Unter [Templates](/de/manual/setup/templates) findest du den vollständigen Ablauf.
  </Step>

  <Step title="Befehle prüfen">
    Weise dir `simplecloud.command.use` zu, verbinde dich über den Proxy und führe `/cloud` aus.

    <Check>
      Das Hilfemenü zeigt alle Unterbefehle, für die du eine Berechtigung hast.
    </Check>
  </Step>
</Steps>

## Befehle

Der Hauptbefehl ist als `/cloud`, `/sc` und `/simplecloud` verfügbar.

### Gruppen

| Befehl | Beschreibung |
| ------ | ------------ |
| `/cloud group list` | Alle Gruppen auflisten |
| `/cloud group info <group>` | Gruppentyp, Arbeitsspeicher, Spielerlimit und Anzahl laufender Server anzeigen |
| `/cloud group start <group> [count]` | Einen oder mehrere neue Server der Gruppe anfordern |
| `/cloud group stop <group> [id]` | Alle laufenden Server einer Gruppe oder eine numerische ID stoppen |

### Server

| Befehl | Beschreibung |
| ------ | ------------ |
| `/cloud server list [group]` | Laufende Server auflisten, optional nach Gruppe gefiltert |
| `/cloud server info <group> <id>` | Status, Arbeitsspeicher und Spieler eines Servers anzeigen |
| `/cloud server start <group>` | Einen neuen Server der Gruppe anfordern |
| `/cloud server stop <group> <id>` | Einen laufenden Server stoppen |

### Spieler

Verwende `group` für eine Servergruppe und `ps` für einen persistenten Server.

| Befehl | Beschreibung |
| ------ | ------------ |
| `/cloud player list <group\|ps> <target>` | Spieler einer Gruppe oder eines persistenten Servers auflisten |
| `/cloud player info <player>` | Verbindungsdaten eines Spielers anzeigen |
| `/cloud player send <player> <group\|ps> <target>` | Einen Spieler zum Ziel senden |
| `/cloud player sendall <group\|ps> <target>` | Alle Online-Spieler zum Ziel senden |
| `/cloud player sendfrom <source> <group\|ps> <target>` | Spieler eines Quellservers zum Ziel senden |
| `/cloud player message <player> <message>` | Einem Spieler eine unformatierte Nachricht senden |

### Konfiguration neu laden

| Befehl | Beschreibung |
| ------ | ------------ |
| `/cloud reload` | `plugins/simplecloud-command/messages.yml` neu laden |

Starte den Proxy neu, wenn du stattdessen die Datei im Template bearbeitet hast.

## Berechtigungen

| Berechtigung | Beschreibung |
| ------------ | ------------ |
| `simplecloud.command.use` | Hauptbefehl verwenden und verfügbare Unterbefehle anzeigen |
| `simplecloud.command.group.list` | `/cloud group list` verwenden |
| `simplecloud.command.group.info` | `/cloud group info` verwenden |
| `simplecloud.command.group.start` | `/cloud group start` verwenden |
| `simplecloud.command.group.stop` | `/cloud group stop` verwenden |
| `simplecloud.command.server.list` | `/cloud server list` verwenden |
| `simplecloud.command.server.info` | `/cloud server info` verwenden |
| `simplecloud.command.server.start` | `/cloud server start` verwenden |
| `simplecloud.command.server.stop` | `/cloud server stop` verwenden |
| `simplecloud.command.player.list` | `/cloud player list` verwenden |
| `simplecloud.command.player.info` | `/cloud player info` verwenden |
| `simplecloud.command.player.send` | Befehle zum Verschieben von Spielern verwenden |
| `simplecloud.command.player.message` | `/cloud player message` verwenden |
| `simplecloud.command.reload` | `/cloud reload` verwenden |

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Der Proxy kann Cloud Command nicht laden">
    Prüfe, ob `simplecloud-api` auf demselben Proxy installiert und aktiviert ist. Cloud Command benötigt dieses Plugin zwingend.
  </Accordion>

  <Accordion title="Ein Befehl fehlt im Hilfemenü">
    Weise die passende Berechtigung zu. Das Hilfemenü blendet Unterbefehle aus, die der Absender nicht verwenden darf.
  </Accordion>

  <Accordion title="Nachrichtenänderungen verschwinden nach einem Neustart">
    Bearbeite `plugins/simplecloud-command/messages.yml` im Proxy-Template oder kopiere die getestete Datei dorthin, bevor ein temporärer Gruppen-Proxy stoppt.
  </Accordion>
</AccordionGroup>
