Die Events API ermöglicht das Reagieren auf Änderungen in deinem Netzwerk in Echtzeit. Zugriff über `api.event()`.

## Event-Kategorien

| Methode | Events |
|---------|--------|
| `api.event().group()` | Gruppe erstellt, aktualisiert, gelöscht |
| `api.event().server()` | Server gestartet, gestoppt, Status geändert, aktualisiert, gelöscht |
| `api.event().persistentServer()` | Persistenter Server erstellt, gestartet, gestoppt, aktualisiert, gelöscht |
| `api.event().blueprint()` | Blueprint erstellt, aktualisiert, gelöscht |

Alle Event-Objekte stellen `getNetworkId()` und `getTimestamp()` bereit.

## Server Events

Server Events werden für laufende Instanzen ausgelöst. Ein Server kann aus einer Gruppe oder aus einem persistenten Server stammen. Nutze das enthaltene `Server`-Model, um die Quelle zu prüfen.

### Server gestartet

```java
Subscription sub = api.event().server().onStarted(event -> {
    Server server = event.getServer();

    System.out.println("Server gestartet: " + event.getServerId());

    if (server.isFromPersistentServer()) {
        System.out.println("Persistenter Server: " + server.getPersistentServerId());
    } else {
        System.out.println("Gruppe: " + server.getGroup().getName());
    }
});
```

### Server gestoppt

```java
api.event().server().onStopped(event -> {
    System.out.println("Server gestoppt: " + event.getServerId());

    if (event.getCrashed()) {
        System.out.println("Exit-Code: " + event.getExitCode());
        System.out.println("Grund: " + event.getReason());
    }
});
```

### Server-Status geändert

```java
api.event().server().onStateChanged(event -> {
    System.out.println(event.getServerId() + ": " +
        event.getOldState() + " -> " + event.getNewState());
});
```

### Server aktualisiert und gelöscht

```java
api.event().server().onUpdated(event -> {
    System.out.println("Server aktualisiert: " + event.getServerId());
});

api.event().server().onDeleted(event -> {
    System.out.println("Server gelöscht: " + event.getServerId());
});
```

## Subscriptions verwalten

Subscriptions implementieren `AutoCloseable`. Räume sie immer auf, wenn du fertig bist.

### Manuelles Aufräumen

```java
Subscription sub = api.event().server().onStarted(event -> {
    System.out.println("Gestartet: " + event.getServer().getServerId());
});

// Später, beim Herunterfahren
sub.close();
```

### Plugin-Lebenszyklus

```java
public class MeinPlugin extends JavaPlugin {
    private final List<Subscription> subscriptions = new ArrayList<>();
    private CloudApi api;

    @Override
    public void onEnable() {
        api = CloudApi.create();

        subscriptions.add(api.event().server().onStarted(this::handleServerStart));
        subscriptions.add(api.event().server().onStopped(this::handleServerStop));
    }

    @Override
    public void onDisable() {
        subscriptions.forEach(Subscription::close);
    }

    private void handleServerStart(ServerStartedEvent event) {
        getLogger().info("Server gestartet: " + event.getServerId());
    }

    private void handleServerStop(ServerStoppedEvent event) {
        getLogger().info("Server gestoppt: " + event.getServerId());
    }
}
```

## Event-Referenz

Felder entsprechen Java-Gettern. `serverId` wird zum Beispiel über `getServerId()` bereitgestellt.

Jedes Event enthält diese gemeinsamen Felder:

<ResponseField name="networkId" type="string">
  Netzwerk-ID, zu der das Event gehört.
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO-8601-Zeitpunkt, zu dem das Event ausgelöst wurde.
</ResponseField>

### Server Events

<AccordionGroup>
  <Accordion title="ServerStartedEvent">
    <ResponseField name="serverId" type="string">
      ID der gestarteten Serverinstanz.
    </ResponseField>

    <ResponseField name="serverGroupId" type="string">
      ID der Servergruppe, zu der dieser Server gehört.
    </ResponseField>

    <ResponseField name="server" type="Server">
      Gestartete Serverinstanz mit vollständiger Konfiguration und Laufzeitinformationen.
    </ResponseField>
  </Accordion>

  <Accordion title="ServerStoppedEvent">
    <ResponseField name="serverId" type="string">
      ID der gestoppten Serverinstanz.
    </ResponseField>

    <ResponseField name="serverGroupId" type="string">
      ID der Servergruppe, zu der dieser Server gehört.
    </ResponseField>

    <ResponseField name="server" type="Server">
      Gestoppte Serverinstanz mit vollständiger Konfiguration und Laufzeitinformationen.
    </ResponseField>

    <ResponseField name="crashed" type="boolean">
      Gibt an, ob der Server unerwartet gestoppt wurde.
    </ResponseField>

    <ResponseField name="exitCode" type="integer | null">
      Exit-Code des Prozesses oder `null`, wenn kein Exit-Code verfügbar ist.
    </ResponseField>

    <ResponseField name="reason" type="string | null">
      Stop-Grund oder `null`, wenn kein Grund verfügbar ist.
    </ResponseField>
  </Accordion>

  <Accordion title="ServerStateChangedEvent">
    <ResponseField name="serverId" type="string">
      ID des Servers, dessen Status sich geändert hat.
    </ResponseField>

    <ResponseField name="oldState" type="ServerState">
      Vorheriger Serverstatus.
    </ResponseField>

    <ResponseField name="newState" type="ServerState">
      Neuer Serverstatus.
    </ResponseField>

    <ResponseField name="server" type="Server">
      Aktuelle Serverinstanz mit vollständiger Konfiguration und Laufzeitinformationen.
    </ResponseField>
  </Accordion>

  <Accordion title="ServerUpdatedEvent">
    <ResponseField name="serverId" type="string">
      ID der aktualisierten Serverinstanz.
    </ResponseField>

    <ResponseField name="serverGroupId" type="string">
      ID der Servergruppe, zu der dieser Server gehört.
    </ResponseField>

    <ResponseField name="server" type="Server">
      Aktualisierte Serverinstanz mit vollständiger Konfiguration und Laufzeitinformationen.
    </ResponseField>
  </Accordion>

  <Accordion title="ServerDeletedEvent">
    <ResponseField name="serverId" type="string">
      ID der gelöschten Serverinstanz.
    </ResponseField>

    <ResponseField name="serverGroupId" type="string">
      ID der Servergruppe, zu der dieser Server gehörte.
    </ResponseField>

    <ResponseField name="server" type="Server">
      Gelöschte Serverinstanz mit den zuletzt verfügbaren Konfigurations- und Laufzeitinformationen.
    </ResponseField>
  </Accordion>
</AccordionGroup>
