title: 'Events API'
description: 'Echtzeit-Events aus deinem Cloud-Netzwerk abonnieren'
---

Die Events API ermöglicht es, in Echtzeit auf Änderungen in deinem Netzwerk zu reagieren. Zugriff über `api.event()`.

## Event-Kategorien

| Methode | Events |
|---------|--------|
| `api.event().group()` | Group erstellt, aktualisiert, gelöscht |
| `api.event().server()` | Server gestartet, gestoppt, State geändert, aktualisiert, gelöscht |
| `api.event().persistentServer()` | Persistent Server erstellt, gestartet, gestoppt, aktualisiert, gelöscht |
| `api.event().blueprint()` | Blueprint erstellt, aktualisiert, gelöscht |

## Server-Events

### Server gestartet

Wird ausgelöst, wenn eine Server-Instanz aktiv wird. Das Event enthält das vollständige `Server`-Objekt mit allen Laufzeitinformationen.

<CodeGroup>
```java Java
Subscription sub = api.event().server().onStarted(event -> {
    System.out.println("Server gestartet: " + event.getServerId());
    System.out.println("Network: " + event.getNetworkId());

    Server server = event.getServer();
    if (server.isFromGroup()) {
        System.out.println("Group: " + server.getServerGroupId());
    } else if (server.isFromPersistentServer()) {
        System.out.println("Persistent Server: " + server.getPersistentServerId());
    }
});
```

```kotlin Kotlin
val sub = api.event().server().onStarted { event ->
    println("Server gestartet: ${event.serverId}")
    println("Network: ${event.networkId}")

    val server = event.server
    if (server.isFromGroup()) {
        println("Group: ${server.serverGroupId}")
    } else if (server.isFromPersistentServer()) {
        println("Persistent Server: ${server.persistentServerId}")
    }
}
```
</CodeGroup>

### Server gestoppt

Wird ausgelöst, wenn eine Server-Instanz stoppt. Mit `getCrashed()` lassen sich unerwartete Abstürze erkennen.

<CodeGroup>
```java Java
api.event().server().onStopped(event -> {
    System.out.println("Server gestoppt: " + event.getServerId());

    if (event.getCrashed()) {
        System.out.println("Server abgestürzt! Exit-Code: " + event.getExitCode());
        System.out.println("Grund: " + event.getReason());
    }
});
```

```kotlin Kotlin
api.event().server().onStopped { event ->
    println("Server gestoppt: ${event.serverId}")

    if (event.crashed) {
        println("Server abgestürzt! Exit-Code: ${event.exitCode}")
        println("Grund: ${event.reason}")
    }
}
```
</CodeGroup>

### Server-State geändert

Wird ausgelöst, wenn ein Server zwischen Lifecycle-States wechselt.

<CodeGroup>
```java Java
api.event().server().onStateChanged(event -> {
    System.out.println(event.getServerId() + ": " +
        event.getOldState() + " → " + event.getNewState());

    if (event.getNewState() == ServerState.AVAILABLE) {
        System.out.println("Server bereit: " + event.getServerId());
    }
});
```

```kotlin Kotlin
api.event().server().onStateChanged { event ->
    println("${event.serverId}: ${event.oldState} → ${event.newState}")

    if (event.newState == ServerState.AVAILABLE) {
        println("Server bereit: ${event.serverId}")
    }
}
```
</CodeGroup>

### Server aktualisiert

Wird ausgelöst, wenn die Konfiguration oder Eigenschaften eines Servers geändert werden.

<CodeGroup>
```java Java
api.event().server().onUpdated(event -> {
    System.out.println("Server aktualisiert: " + event.getServerId());
    Server server = event.getServer();
    System.out.println("Spieleranzahl: " + server.getPlayerCount());
});
```

```kotlin Kotlin
api.event().server().onUpdated { event ->
    println("Server aktualisiert: ${event.serverId}")
    val server = event.server
    println("Spieleranzahl: ${server.playerCount}")
}
```
</CodeGroup>

### Server gelöscht

Wird ausgelöst, wenn ein Server-Datensatz entfernt wird.

<CodeGroup>
```java Java
api.event().server().onDeleted(event -> {
    System.out.println("Server gelöscht: " + event.getServerId());
});
```

```kotlin Kotlin
api.event().server().onDeleted { event ->
    println("Server gelöscht: ${event.serverId}")
}
```
</CodeGroup>

## Subscriptions verwalten

Subscriptions implementieren `AutoCloseable`. Räume sie immer auf, wenn du sie nicht mehr brauchst.

### Manuelles Aufräumen

<CodeGroup>
```java Java
Subscription sub = api.event().server().onStarted(event -> { ... });

// Beim Herunterfahren
sub.close();
```

```kotlin Kotlin
val sub = api.event().server().onStarted { event -> /* ... */ }

// Beim Herunterfahren
sub.close()
```
</CodeGroup>

### Try-with-Resources

<CodeGroup>
```java Java
try (Subscription sub = api.event().server().onStarted(event -> { ... })) {
    // Subscription innerhalb dieses Blocks aktiv
    Thread.sleep(60000);
} // Wird automatisch geschlossen
```

```kotlin Kotlin
api.event().server().onStarted { event -> /* ... */ }.use {
    // Subscription innerhalb dieses Blocks aktiv
    Thread.sleep(60000)
} // Wird automatisch geschlossen
```
</CodeGroup>

### Plugin-Lifecycle

<CodeGroup>
```java Java
public class MyPlugin extends JavaPlugin {
    private final List<Subscription> subscriptions = new ArrayList<>();
    private CloudApi api;

    @Override
    public void onEnable() {
        api = CloudApi.create();

        subscriptions.add(api.event().server().onStarted(this::handleServerStart));
        subscriptions.add(api.event().server().onStopped(this::handleServerStop));
        subscriptions.add(api.event().group().onUpdated(this::handleGroupUpdate));
    }

    @Override
    public void onDisable() {
        subscriptions.forEach(Subscription::close);
        subscriptions.clear();
    }

    private void handleServerStart(ServerStartedEvent event) {
        getLogger().info("Server gestartet: " + event.getServerId());
    }

    private void handleServerStop(ServerStoppedEvent event) {
        getLogger().info("Server gestoppt: " + event.getServerId());
    }

    private void handleGroupUpdate(GroupUpdatedEvent event) {
        getLogger().info("Group aktualisiert: " + event.getServerGroupId());
    }
}
```

```kotlin Kotlin
class MyPlugin : JavaPlugin() {
    private val subscriptions = mutableListOf<Subscription>()
    private lateinit var api: CloudApi

    override fun onEnable() {
        api = CloudApi.create()

        subscriptions.add(api.event().server().onStarted(::handleServerStart))
        subscriptions.add(api.event().server().onStopped(::handleServerStop))
        subscriptions.add(api.event().group().onUpdated(::handleGroupUpdate))
    }

    override fun onDisable() {
        subscriptions.forEach { it.close() }
        subscriptions.clear()
    }

    private fun handleServerStart(event: ServerStartedEvent) {
        logger.info("Server gestartet: ${event.serverId}")
    }

    private fun handleServerStop(event: ServerStoppedEvent) {
        logger.info("Server gestoppt: ${event.serverId}")
    }

    private fun handleGroupUpdate(event: GroupUpdatedEvent) {
        logger.info("Group aktualisiert: ${event.serverGroupId}")
    }
}
```
</CodeGroup>

## Event-Referenz

### Server-Events

| Event | Wichtige Eigenschaften |
|-------|------------------------|
| `ServerStartedEvent` | `serverId`, `serverGroupId`, `server`, `networkId`, `timestamp` |
| `ServerStoppedEvent` | `serverId`, `serverGroupId`, `server`, `crashed`, `exitCode`, `reason`, `networkId`, `timestamp` |
| `ServerStateChangedEvent` | `serverId`, `oldState`, `newState`, `server`, `networkId`, `timestamp` |
| `ServerUpdatedEvent` | `serverId`, `serverGroupId`, `server`, `networkId`, `timestamp` |
| `ServerDeletedEvent` | `serverId`, `serverGroupId`, `server`, `networkId`, `timestamp` |

<Note>
  `ServerStartedEvent` und `ServerStoppedEvent` werden sowohl für Group-Server als auch für Persistent Server ausgelöst. Nutze `server.isFromGroup()` oder `server.isFromPersistentServer()`, um sie zu unterscheiden.
</Note>

### Group-Events

| Event | Wichtige Eigenschaften |
|-------|------------------------|
| `GroupCreatedEvent` | `serverGroupId`, `group`, `networkId`, `timestamp` |
| `GroupUpdatedEvent` | `serverGroupId`, `group`, `networkId`, `timestamp` |
| `GroupDeletedEvent` | `serverGroupId`, `name`, `networkId`, `timestamp` |

### Persistent-Server-Events

| Event | Wichtige Eigenschaften |
|-------|------------------------|
| `PersistentServerCreatedEvent` | `persistentServerId`, `name`, `networkId`, `timestamp` |
| `PersistentServerStartedEvent` | `persistentServerId`, `serverId`, `networkId`, `timestamp` |
| `PersistentServerStoppedEvent` | `persistentServerId`, `serverId`, `networkId`, `timestamp` |
| `PersistentServerUpdatedEvent` | `persistentServerId`, `name`, `networkId`, `timestamp` |
| `PersistentServerDeletedEvent` | `persistentServerId`, `name`, `networkId`, `timestamp` |

### Blueprint-Events

| Event | Wichtige Eigenschaften |
|-------|------------------------|
| `BlueprintCreatedEvent` | `blueprintId`, `blueprint`, `networkId`, `timestamp` |
| `BlueprintUpdatedEvent` | `blueprintId`, `blueprint`, `networkId`, `timestamp` |
| `BlueprintDeletedEvent` | `blueprintId`, `name`, `networkId`, `timestamp` |
