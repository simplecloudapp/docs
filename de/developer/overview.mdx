---
title: "Cloud API"
description: "Entwickle Minecraft-Plugins, die mit deinem SimpleCloud-Netzwerk zusammenarbeiten"
---

Die Cloud API verbindet dein Java- oder Kotlin-Minecraft-Plugin mit SimpleCloud. Nutze sie, um den aktuellen Zustand deines Netzwerks abzufragen, zu verwalten und auf Änderungen zu reagieren.

Mit der Cloud API kannst du:

- Servergruppen erstellen und konfigurieren
- langlebige persistente Server verwalten
- laufende Serverinstanzen finden und aktualisieren
- Spieler suchen, ihnen Nachrichten senden und sie zwischen Servern verschieben
- auf Änderungen an Ressourcen in deinem Netzwerk reagieren
