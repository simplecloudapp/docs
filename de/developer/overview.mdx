Die Cloud API ist eine Java-Bibliothek zur programmatischen Interaktion mit deinem SimpleCloud-Netzwerk. Nutze sie, um Groups, Server, Persistent Server und Spieler zu verwalten und in Echtzeit auf Events zu reagieren.

## API-Architektur

| Methode | Gibt zurück | Beschreibung |
|---------|-------------|--------------|
| `api.group()` | `GroupApi` | Groups erstellen, lesen, aktualisieren, löschen |
| `api.server()` | `ServerApi` | Server-Instanzen abfragen, stoppen, aktualisieren |
| `api.persistentServer()` | `PersistentServerApi` | Persistent Server erstellen, lesen, aktualisieren, löschen |
| `api.player()` | `PlayerApi` | Spielerdaten, Verbindungen, Messaging |
| `api.event()` | `EventApi` | Echtzeit-Events abonnieren |
| `api.cache()` | `QueryCache` | Cache manuell inspizieren und invalidieren |

### Event API Unterkategorien

| Methode | Beschreibung |
|---------|--------------|
| `api.event().group()` | Group-Lifecycle-Events |
| `api.event().server()` | Server-Lifecycle-Events |
| `api.event().persistentServer()` | Persistent-Server-Events |
| `api.event().blueprint()` | Blueprint-Lifecycle-Events |

## Wichtige Features

- **Async-first-Design** Alle Operationen geben `CompletableFuture` zurück
- **Typsichere Modelle** Stark typisierte Domain-Objekte für Groups, Server, Spieler, Persistent Server und Blueprints
- **Echtzeit-Events** Änderungen über NATS-Messaging abonnieren
- **Eingebauter Cache** TanStack-Query-ähnliches Stale-while-revalidate-Caching, automatisch invalidiert durch Events
- **Adventure-Integration** Spieler implementieren Adventures `Audience`-Interface für Rich-Text-Messaging
- **Umgebungs-bewusst** Automatische Konfiguration aus `SIMPLECLOUD_*`-Umgebungsvariablen

## Schnellbeispiel

<Tabs>
<Tab title="Java">

```java
// API initialisieren
CloudApi api = CloudApi.create();

// Alle Server einer Group abrufen
api.server().getServersByGroup("lobby").thenAccept(servers -> {
    System.out.println("Lobby-Server: " + servers.size());
});

// Neuen Server für eine Group starten
api.group().getGroupByName("lobby")
    .thenCompose(group -> api.group().requestServerStart(group))
    .thenRun(() -> System.out.println("Start-Anfrage für lobby akzeptiert"));

// Nachricht an Spieler senden (Adventure-Integration)
api.player().get(playerUUID).thenAccept(player -> {
    if (player != null) {
        player.sendMessage(Component.text("Willkommen!").color(NamedTextColor.GREEN));
    }
});

// Server-Events abonnieren
Subscription sub = api.event().server().onStarted(event -> {
    System.out.println("Server gestartet: " + event.getServerId());
});
```

</Tab>
<Tab title="Kotlin">

```kotlin
// API initialisieren
val api = CloudApi.create()

// in einem Coroutine-Scope (z. B. Plugin-Lifecycle oder launch { })

// Alle Server einer Group abrufen
val servers = api.server().getServersByGroup("lobby").await()
println("Lobby-Server: ${servers.size}")

// Neuen Server für eine Group starten
val group = api.group().getGroupByName("lobby").await()
api.group().requestServerStart(group).await()
println("Start-Anfrage für lobby akzeptiert")

// Nachricht an Spieler senden (Adventure-Integration)
val player = api.player().get(playerUUID).await()
player?.sendMessage(Component.text("Willkommen!").color(NamedTextColor.GREEN))

// Server-Events abonnieren
val sub = api.event().server().onStarted { event ->
    println("Server gestartet: ${event.serverId}")
}
```
