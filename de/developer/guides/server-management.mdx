---

Wenn ein Spieler einen Server benötigt, frage die Gruppe nach verfügbarer Kapazität ab und verbinde ihn mit der am wenigsten ausgelasteten Instanz.

<Note>
  Lass SimpleCloud die Anzahl der Server in einer Gruppe verwalten. Dieser Ablauf wählt nur aus den Instanzen aus, die jetzt bereit sind.
</Note>

## Spieler zu einer Gruppe weiterleiten

Der folgende Router sucht spielbereite Server in einer Gruppe, ignoriert volle Instanzen und versucht, eine Verbindung herzustellen. Er gibt `NoCapacity` zurück, wenn kein geeigneter Server verfügbar ist, und andernfalls `ConnectionAttempted` mit dem Ergebnis von `CloudPlayer.connect`.

```java GroupRouter.java
package com.example;

import app.simplecloud.api.CloudApi;
import app.simplecloud.api.player.CloudPlayer;
import app.simplecloud.api.server.Server;
import app.simplecloud.api.server.ServerQuery;
import app.simplecloud.api.server.ServerState;

import java.util.Comparator;
import java.util.concurrent.CompletableFuture;

public final class GroupRouter {
    private final CloudApi api;

    public GroupRouter(CloudApi api) {
        this.api = api;
    }

    public CompletableFuture<RouteResult> routeToGroup(
        CloudPlayer player,
        String groupName
    ) {
        ServerQuery query = ServerQuery.create()
            .filterByServerGroupName(groupName)
            .filterByState(ServerState.AVAILABLE, ServerState.INGAME);

        return api.server().getAllServers(query).thenCompose(servers -> servers.stream()
            .filter(server -> server.getPlayerCount() != null)
            .filter(server -> server.getPlayerCount() < server.getMaxPlayers())
            .min(Comparator
                .comparingInt((Server server) -> server.getPlayerCount())
                .thenComparingInt(Server::getNumericalId))
            .<CompletableFuture<RouteResult>>map(server -> {
                String serverName = groupName + "-" + server.getNumericalId();
                return player.connect(serverName)
                    .thenApply(RouteResult.ConnectionAttempted::new);
            })
            .orElseGet(() -> CompletableFuture.completedFuture(
                new RouteResult.NoCapacity()
            )));
    }

    public sealed interface RouteResult {
        record NoCapacity() implements RouteResult {}

        record ConnectionAttempted(
            CloudPlayer.ConnectResult result
        ) implements RouteResult {}
    }
}
```

Server im Zustand `AVAILABLE` und `INGAME` können Spieler annehmen. Die Sortierung nach Spieleranzahl verteilt neue Verbindungen auf die Gruppe; die numerische ID sorgt bei Gleichstand für eine stabile Auswahl.

Der Servername folgt dem standardmäßigen Registrierungsmuster `<groupName>-<numericalId>` von SimpleCloud, zum Beispiel `lobby-3`. Wenn du das Registrierungsmuster geändert hast, setze den Namen hier nach demselben Muster zusammen.

Behandle `NoCapacity`, indem du den Spieler in deiner Warteschlange oder Fallback-Lobby lässt. Verwende bei `ConnectionAttempted` das zurückgegebene `ConnectResult`, um die Verbindung zu bestätigen oder einen geeigneten Fallback anzuzeigen.

## Nächste Schritte

- Verwende die [Groups API](/de/developer/api/groups), um Gruppen zu erstellen und zu konfigurieren.
- Verwende den [Leitfaden zur Event-Verarbeitung](/de/developer/guides/event-handling), wenn dein Plugin reagieren soll, sobald Server verfügbar werden.
- In der [Servers API](/de/developer/api/servers) findest du Serverabfragen, Modelle und Lebenszyklusaktionen.
