## Spieler verschieben

Installiere zuerst die [Cloud API](/de/developer/installation), füge das Plattform-Plugin `simplecloud-api` als Abhängigkeit hinzu und verwende einen gemeinsamen `CloudApi`-Client. Installiere `simplecloud-api` auf jedem Proxy, der den Spieler verarbeiten kann, da dieser Proxy die Verbindung herstellt.

Übergib den registrierten Servernamen, zum Beispiel `lobby-1`, statt der von `Server.getServerId()` zurückgegebenen UUID.

Dieses vollständige Beispiel sucht den Spieler anhand seiner UUID, prüft seinen Online-Status und verarbeitet jedes Verbindungsergebnis:

```java PlayerTransferService.java
import app.simplecloud.api.CloudApi;
import app.simplecloud.api.player.CloudPlayer;

import java.util.UUID;
import java.util.concurrent.CompletableFuture;
import java.util.logging.Level;
import java.util.logging.Logger;

public final class PlayerTransferService {
    private final CloudApi api;
    private final Logger logger;

    public PlayerTransferService(CloudApi api, Logger logger) {
        this.api = api;
        this.logger = logger;
    }

    public CompletableFuture<CloudPlayer.ConnectResult> transfer(
        UUID playerId,
        String registeredServerName
    ) {
        return api.player().get(playerId).thenCompose(player -> {
            if (player == null || !player.isOnline()) {
                return CompletableFuture.completedFuture(
                    CloudPlayer.ConnectResult.PLAYER_NOT_FOUND
                );
            }

            return player.connect(registeredServerName);
        });
    }

    public void transferToLobby(UUID playerId) {
        transfer(playerId, "lobby-1")
            .thenAccept(result -> {
                switch (result) {
                    case SUCCESS, ALREADY_CONNECTED ->
                        logger.info("Spieler ist mit lobby-1 verbunden");
                    case SERVER_NOT_FOUND ->
                        logger.warning("lobby-1 ist nicht auf dem Proxy registriert");
                    case PLAYER_NOT_FOUND ->
                        logger.info("Spieler ist nicht mehr online");
                    case CONNECTION_FAILED ->
                        logger.warning("Spieler konnte nicht mit lobby-1 verbunden werden");
                }
            })
            .exceptionally(error -> {
                logger.log(Level.WARNING, "Spieler konnte nicht verschoben werden", error);
                return null;
            });
    }
}
```

Erzeuge einen `PlayerTransferService` mit dem gemeinsamen `CloudApi`-Client und Logger deines Plugins. Rufe `transferToLobby(...)` aus deinem Befehls- oder Matchmaking-Ablauf auf.

Der Service gibt `PLAYER_NOT_FOUND` zurück, wenn die Suche keinen Online-Spieler findet. Trennt der Spieler danach die Verbindung, gibt `connect(...)` den Wert `CONNECTION_FAILED` zurück.

## Verbindungsergebnisse

| Ergebnis | Bedeutung |
| -------- | --------- |
| `SUCCESS` | Der Spieler wurde mit dem Ziel verbunden. |
| `ALREADY_CONNECTED` | Der Spieler ist bereits mit dem Ziel verbunden. |
| `SERVER_NOT_FOUND` | Der übergebene Name ist auf dem Proxy des Spielers nicht registriert. |
| `PLAYER_NOT_FOUND` | Die Suche des Beispiels hat keinen Online-Spieler gefunden. |
| `CONNECTION_FAILED` | Der Proxy konnte die Verbindung nicht herstellen. |

Wenn dein Plugin zuerst ein verfügbares Ziel suchen muss, lies [Spieler mit Autoscaling weiterleiten](/de/developer/guides/server-management).
