---
title: "Spieler auf einen anderen Server verschieben"
description: "Verbinde einen Spieler, der online ist, mit einem bekannten Server und verarbeite das Ergebnis"
---

Verwende `CloudPlayer.connect(...)`, wenn du bereits weißt, welchem Server der Spieler beitreten soll. Die Methode erwartet den auf dem Proxy des Spielers registrierten Namen, zum Beispiel `lobby-1` – nicht die von `Server.getServerId()` zurückgegebene Server-UUID.

## Spieler verschieben

Suche den Spieler anhand seiner UUID, prüfe, ob er online ist, und verbinde ihn mit dem registrierten Servernamen:

```java PlayerTransferService.java
import app.simplecloud.api.CloudApi;
import app.simplecloud.api.player.CloudPlayer;

import java.util.UUID;
import java.util.concurrent.CompletableFuture;

public final class PlayerTransferService {
    private final CloudApi api;

    public PlayerTransferService(CloudApi api) {
        this.api = api;
    }

    public CompletableFuture<CloudPlayer.ConnectResult> transfer(
        UUID playerId,
        String registeredServerName
    ) {
        return api.player().get(playerId).thenCompose(player -> {
            if (player == null || !player.isOnline()) {
                return CompletableFuture.completedFuture(
                    CloudPlayer.ConnectResult.PLAYER_NOT_FOUND
                );
            }

            return player.connect(registeredServerName);
        });
    }
}
```

Rufe `transfer(...)` aus deinem Befehls- oder Matchmaking-Ablauf auf und verarbeite das Ergebnis:

```java
transferService.transfer(playerId, "lobby-1")
    .thenAccept(result -> {
        switch (result) {
            case SUCCESS, ALREADY_CONNECTED ->
                logger.info("Player is connected to lobby-1");
            case SERVER_NOT_FOUND ->
                logger.warning("lobby-1 is not registered on the proxy");
            case PLAYER_NOT_FOUND ->
                logger.info("Player is no longer online");
            case CONNECTION_FAILED ->
                logger.warning("Could not connect player to lobby-1");
        }
    })
    .exceptionally(error -> {
        logger.log(Level.WARNING, "Could not transfer player", error);
        return null;
    });
```

Dieser Leitfaden gibt `PLAYER_NOT_FOUND` zurück, wenn die Suche keinen Spieler findet, der online ist. Wenn der Spieler die Verbindung nach dieser Prüfung trennt, gibt `connect(...)` den Wert `CONNECTION_FAILED` zurück.

## Verbindungsergebnisse

| Ergebnis | Bedeutung |
| --- | --- |
| `SUCCESS` | Der Spieler wurde mit dem Ziel verbunden. |
| `ALREADY_CONNECTED` | Der Spieler ist bereits mit dem Ziel verbunden. |
| `SERVER_NOT_FOUND` | Der übergebene Name ist auf dem Proxy des Spielers nicht registriert. |
| `PLAYER_NOT_FOUND` | Die Suche dieses Leitfadens hat keinen Spieler gefunden, der online ist. |
| `CONNECTION_FAILED` | Der Proxy konnte die Verbindung nicht herstellen. |

Wenn dein Plugin zuerst ein verfügbares Ziel finden muss, lies [Spieler mit Autoscaling weiterleiten](/de/developer/guides/server-management).
